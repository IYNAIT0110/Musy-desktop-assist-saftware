# Musy 使用指南

> 适用于 Musy v0.1.x（Windows 10 / 11 x64）
> 遇到问题先看最后一节「常见问题」。

---

## 1. 安装与启动

### 1.1 选哪个版本

| 版本 | 文件名 | 适合谁 |
| --- | --- | --- |
| 安装版 | `musy-desktop-assist-0.1.3-setup.exe` | 长期使用，想有桌面快捷方式、开始菜单项，可正常卸载 |
| 便携版 | `musy-desktop-assist-0.1.3-portable.exe` | 临时用、放在 U 盘、或者公司电脑不方便装软件 |

两个版本功能完全一样，数据也是同一份。**不要同时运行两个版本**（单实例锁会自动阻止，只会把已有窗口唤到前台）。

### 1.2 安装步骤

1. 双击 `setup.exe`
2. 首次运行 Windows 可能弹「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」
   （程序没有购买代码签名证书，属于正常现象，不是病毒提示）
3. 选择安装目录（默认 `%LOCALAPPDATA%\Programs\Musy桌面助手`）→ 安装
4. 安装完成后桌面会出现「Musy桌面助手」快捷方式

卸载：设置 → 应用 → 找到「Musy桌面助手」→ 卸载。卸载**不会**删除你的数据（见第 7 节手动清理）。

### 1.3 启动后看到什么

启动后不会弹出大窗口，而是**屏幕左侧偏上**出现一个 64×64 的黑色小球（缪斯吉祥物），它不会抢焦点、不会挡住任务栏，鼠标划过时眼睛会跟着光标转。

## 2. 界面与形态

Musy 有四种形态，逐级展开、逐级收起：

```
① 悬浮球 64×64
      │ 点击小球
      ▼
② 功能胶囊 296×64   ← 链接 / 提示词 / 快捷键 / 润色 / 模型库
      │ 点击某个功能图标
      ▼
③ 完整面板 760×560  ← 出现标题栏 + 设置/收起/最小化/退出
      │ 点击一张提示词卡片
      ▼
④ 提示词工作区 760×980
```

| 操作 | 结果 |
| --- | --- |
| 点击小球 | 展开 / 收起胶囊（收起时若面板开着会一起收起） |
| 按住小球拖动 | 移动整个悬浮条（鼠标变成抓手） |
| 点击功能图标 | 展开对应模块的面板 |
| 标题栏 ⤡ | 收起面板回到胶囊（面板状态保留，再点会回到原模块） |
| 标题栏 — | 最小化到任务栏：面板状态不丢，点任务栏图标原样恢复 |
| 标题栏 ⚙ | 打开设置 |
| 标题栏 ⏻ | 退出 Musy（完全关闭进程） |

> 面板展开时会自动检查屏幕边界，靠近屏幕右/下边缘时会自动往回让，不会跑到屏幕外面。

## 3. 链接收藏

### 3.1 收藏一个链接

1. 在任何地方复制一个网址（`Ctrl+C`）
2. 打开链接面板，点左上角「**+ 收藏剪贴板**」
3. 标题自动取域名（如 `i-mad.com` → `i-mad`），点卡片即可用系统浏览器打开

已存在的网址会提示重复，不会重复收藏。非 http/https 的地址（如 `ftp://`、`file://`）会被拒绝。

### 3.2 分组管理

左侧是整理栏：

| 元素 | 说明 |
| --- | --- |
| 全部 | 显示所有链接（默认） |
| 分组名 | 点一下只看该分组 |
| 分组右侧 ✎ | 重命名分组（会同步更新该组所有链接） |
| 分组右侧 🗑 | 删除分组，组内链接自动归入「默认」，不会丢失 |
| 底部「+ 新建分组」 | 输入名字回车即创建 |

### 3.3 移动与排序

- **拖拽**：按住卡片拖到另一张卡片的位置 → 松开即换位（顺序会保存）
- **右键卡片**：弹出「移动到分组」，选一个目标分组即可

### 3.4 网站简介与图标

- 鼠标悬停卡片会浮出简介气泡
- 简介来源：内置数据自带；你自己新收藏的链接，如果配置了大模型，会在后台自动生成一句话简介
- 图标会自动抓取并缓存到本地，第二次打开是秒出的；抓不到图标的站点会显示首字母方块

### 3.5 删除

悬停卡片 → 右上角出现 ✕ → 点击即删除（链接类删除是立即生效的，删错了只能重新收藏）。

## 4. 提示词收藏

### 4.1 新增一条提示词

1. 链接面板上方切到「**提示词**」标签
2. 点右上角「**新增**」
3. 填写：
   - **效果预览图**：点图片区域时，如果剪贴板里有图，会**优先用剪贴板里的图**；没有则弹出文件选择
   - **提示词正文**：必填
   - **标签**：输入后回车，可多个（如 `建筑`、`写实`、`项目A`）
   - **备注**：可选，用来记模型和参数（如 `SDXL, 1024x1024, CFG 7`）
4. 点「保存」

> 图片会自动压缩到长边 1280px 再入库，避免几张原图就把本地存储撑满。

### 4.2 卡片怎么用

卡片上只显示**预览图 + 标签**（避免长提示词把网格撑乱）：

- **鼠标悬停**：卡片上浮，出现右上角的操作按钮；同时底部浮出提示词文本层，**可以滚轮滚动**看完整长提示词
- **点击卡片**：进入四级工作区（见 4.3）
- **标签筛选**：面板顶部一行标签，点任意标签只看该类；再点「全部」恢复

### 4.3 提示词工作区（点开卡片后）

布局：左边主图 + 下面一排子提示词缩略图；右边正文、标签和操作条。

**图片区**

| 操作 | 说明 |
| --- | --- |
| 单击图片 | 全屏预览完整尺寸图片，点击任意处关闭 |
| 悬停图片上沿 → 选择图片 | 用本地文件替换预览图 |
| 悬停图片上沿 → 点击粘贴 | 用剪贴板里的截图替换预览图 |

**正文与标签**

| 操作 | 说明 |
| --- | --- |
| 编辑（✎） | 正文变成可编辑文本框，改完点「保存」；`Ctrl+Enter` 也能保存 |
| 标签 ✕ | 删除某个标签 |
| + 添加 | 输入新标签回车添加 |

**底部操作条**

| 按钮 | 说明 |
| --- | --- |
| 扩写 | 调大模型把当前提示词写得更丰富（补光线、材质、构图、镜头、氛围） |
| 翻译 | 中文→英文，英文→中文 |
| 复制 | 复制正文到剪贴板，按钮上会短暂显示「已复制 ✓」 |
| 保存为子提示词 | 把 AI 扩写/翻译的**结果**存成当前提示词的子提示词 |
| 编辑 | 进入正文编辑态（编辑态下这个位置会变成「保存」和「保存为子提示词」两个按钮） |
| 删除 | 第一次点击变成红色「删除」二字，**再点一次**才真正删除（防止误删） |
| ✕（右下角） | 退出工作区 |

### 4.4 母提示词与子提示词

一条提示词可以有多个「改写版本」，这就是子提示词：

- 在母提示词的详情里点「保存为子提示词」→ 新版本挂在当前提示词下
- 缩略图条上会显示所有子提示词，**点击缩略图**直接跳过去看对应的图和文本
- 在子提示词里再点「保存为子提示词」，新条目会挂到**同一个母提示词**下（成为同级），**不会**出现「子提示词的子提示词」
- 子提示词不出现在主网格里（避免重复占位），只通过母提示词进入
- 删除母提示词会**连带删除**它下面所有子提示词，删除前请确认

### 4.5 AI 扩写 / 翻译前置条件

需要在「设置 → 模型配置」里填好接口地址、API Key、模型名，详见第 6 节。没配置时点按钮会提示「请先在设置里配置 API Key」。

> 模型必须兼容 OpenAI 的 `/chat/completions` 接口。常见可用：DeepSeek、通义千问、智谱 GLM、Kimi、豆包、硅基流动、OpenAI、OpenRouter。

### 4.6 存储提示

预览图存在浏览器本地存储里，配额约 5MB。如果出现「本地存储空间已满」：

1. 删掉一些带图的提示词（尤其是大截图）
2. 或者进入「设置 → 数据路径」选一个文件夹，把数据同步成文件备份后再清理

## 5. 软件快捷键白皮书

内置三套：**SketchUp、Rhino、AutoCAD**，共 234 条，按功能分类（绘图、修改、标注、视图、图层等）。

| 操作 | 说明 |
| --- | --- |
| 点击封面卡片 | 打开该软件的快捷键清单 |
| 左上角 ← | 返回封面列表 |
| 顶部搜索框 | 输入中文命令名、别名或英文命令代码都能搜，例如 `倒角`、`Fillet`、`chamfer` |

快捷键行右侧的按键标签是等宽字体，方便快速扫读。

## 6. 设置

点标题栏 ⚙ 打开，左侧三个页签：

### 6.1 模型配置

| 字段 | 说明 |
| --- | --- |
| 模型服务商 | 8 家预设（DeepSeek / 通义千问 / 智谱 GLM / Moonshot Kimi / 字节豆包 / 硅基流动 / OpenAI / OpenRouter）+ 自定义 |
| 接口地址 | OpenAI 兼容的 base URL，例如 `https://api.deepseek.com/v1`（末尾不要带 `/chat/completions`） |
| API Key | 只存在本机，眼睛图标可切换明文 |
| 模型 | 下拉选择预设模型；下面那行可以手动输入预设以外的模型名 |

填完点「保存配置」。配置只影响 AI 相关功能（网站简介、扩写、翻译）。

### 6.2 数据路径

- 默认不写盘，数据只在浏览器本地存储里
- 选一个文件夹后：**每次改动都会把全量数据写成 `musy-data.json`**（含链接、分组、提示词、图片）
- 用于备份、网盘同步、换电脑迁移

### 6.3 语言

- 内置：简体中文 / English / 日本語，切换立即生效
- 自定义语言包：选一个 JSON 文件，格式是扁平的键值对，会**覆盖**内置文案，例如：

```json
{
  "nav.links": "Links",
  "nav.prompts": "Prompts",
  "prompts.add": "New"
}
```

- 想看有哪些键？在安装目录的资源里能看到全部键名，或参考源码 `src/renderer/src/i18n.ts`
- 「清除」按钮恢复内置文案

## 7. 数据、备份与迁移

### 7.1 数据存在哪

| 内容 | 位置 |
| --- | --- |
| 全部数据（本地存储） | `%APPDATA%\musy-desktop-assist\` |
| 图标缓存 | `%APPDATA%\musy-desktop-assist\favicons\` |
| 你选的数据文件夹 | 你指定的目录 `musy-data.json` |

### 7.2 换电脑 / 重装

**方式一（推荐，完整）**

1. 旧电脑：设置 → 数据路径 → 选一个文件夹（如 `D:\Musy备份`）→ 会自动生成 `musy-data.json`
2. 把该文件拷到新电脑
3. 新电脑：安装 Musy → 设置 → 数据路径 → 点击「从 musy-data.json 恢复」，选择拷来的文件
4. 确认替换当前链接、分组和提示词；导入成功后界面自动刷新

> 选择数据保存文件夹只会写出备份，不会自动读取其中已有的文件。导入操作会替换当前收藏，请先保留原文件副本。

**方式二（最省事）**

直接复制整个 `%APPDATA%\musy-desktop-assist` 文件夹到新电脑相同位置（先在旧电脑退出 Musy）。

> 注意：便携版和安装版共用同一个数据目录，所以换版本不会丢数据。

### 7.3 彻底清除数据

退出 Musy（标题栏 ⏻），删除 `%APPDATA%\musy-desktop-assist` 文件夹即可。下次启动会重新写入内置的链接和快捷键数据。

## 8. 常见问题

### 小球找不到了 / 点不出来

1. 先看任务栏有没有 Musy 图标（可能被最小化到任务栏），点一下即可恢复
2. 双击桌面快捷方式——单实例锁会把已有窗口唤到前台
3. 如果多显示器、或改过分辨率导致它跑到屏幕外：退出后重新启动，位置会重置到左侧偏上

### 网站图标显示成首字母

图标是联网抓的，部分站点本身没提供 favicon，或当前网络访问不到图标服务，就会回落成首字母。属于正常降级，不影响打开网站。

### AI 功能报错

按顺序检查：

1. 接口地址是否少了 `/v1`，或多了 `/chat/completions`
2. API Key 是否过期、余额是否充足
3. 模型名是否是该服务商真实存在的模型（可以在「模型」下拉里重选一次）
4. 公司网络是否拦截了该域名（换手机热点试一下）

报错信息会以红色提示显示在操作条上方。

### 提示「本地存储空间已满」

预览图占满了本地存储（约 5MB）。处理方式见 4.6。

### 提示词删错了能恢复吗

不能，删除是即时的。建议先按 7.2 配置数据文件夹，之后每次改动都有 `musy-data.json` 可回溯。

### 会不会偷偷上传我的数据

不会。除了「抓取网站图标」「调用你自己配置的大模型接口」这两类请求，Musy 不向任何服务器发送数据；没有统计、没有账号体系。
