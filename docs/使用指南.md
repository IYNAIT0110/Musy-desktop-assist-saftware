# Musy 使用指南

适用版本：v0.2.1 · Windows 10 / 11 x64 · 更新于 2026-10-27。

[文档目录](README.md) · [下载最新版](https://github.com/IYNAIT0110/Musy-desktop-assist-saftware/releases/latest) · [备份与迁移](数据与迁移.md)

## v0.2.1 新增功能

v0.2.1 在原有收集、预览与复用基础上新增：

- **织梦台**：第六个导航入口，用于新建、编辑、切换和归档项目。网站、母子卷轴和百宝匣素材可关联多个项目，并在项目内统一搜索、打开或复制。
- **自动关联**：左键顶栏中间的项目胶囊选择项目，右键切换自动关联。开启后，新收藏、卷轴保存与素材导入（含小球快捷保存）会关联该项目。原有项目默认保持手动模式。收集入口可选「本次仅存公共库」；网址气泡另有「公共库」按钮，拖入时按住 Alt 也可仅存公共库。
- **回收区清理**：移入满 30 天后自动清理，支持手动永久删除。外部引用原文件保留；库内条目、自有封面/缓存及软件保存的剪贴板原件会清除。软件关闭期间到期的条目，在下次打开对应资料库时补清理。
- **继续工作**：织梦台内显示从这里成功打开或复制的项目资料，方便继续使用；不跟踪其他软件的操作。
- **云白外观**：设置 → 外观 → 整体配色 → 云白；共 13 套配色，右下角字标随主题保持清晰。
- **致谢与反馈**：设置 → 致谢与反馈，查看主要开源项目、许可说明及 GitHub 问题反馈入口。

项目支持取消关联、撤销和独立关联备份；不会移动素材原件。完整流程、异常处理与换电脑说明见[织梦台与项目关联](织梦台与项目关联.md)。

## 1. 安装与升级

下载 `musy-desktop-assist-0.2.1-setup.exe`，选择目录并安装；无需开发环境。免安装启动版为 `musy-desktop-assist-0.2.1-portable.exe`，首次解压可能稍慢。两者共用当前账户的应用数据和单实例锁，运行另一个版本会唤起已有实例。

升级前备份收藏、卷轴和百宝匣，退出旧版后安装新版。升级不会主动清空用户数据，卸载默认也保留应用数据。便携版不是包含全部个人数据的迁移包。

未签名应用可能显示未知发布者。请核对下载来源和 `SHA256SUMS.txt` 后自行决定是否运行。

## 2. 小球与导航

启动后，小球出现在屏幕左侧。按住拖动可调整位置，单击展开胶囊，再点图标进入模块。

| 入口 | 作用 |
| --- | --- |
| 传送门 | 网站收藏 |
| 卷轴 | 提示词与母子版本 |
| 秘籍 | 软件快捷键参考 |
| 点睛笔 | 独立文字润色，目前为规划占位 |
| 百宝匣 | 文件与图片收集、分类、预览和复用 |
| 织梦台 | 项目管理、多项目关联和统一检索 |

右侧四个按钮为设置、收起/展开面板、最小化到任务栏、退出。最小化后点任务栏图标恢复；再次启动也会唤起已有实例。当前没有系统级全局唤起快捷键。

面板按屏幕工作区调整高度。小球和二级胶囊共用纵向透明画布，上下留白用于导航动画且穿透鼠标。

## 3. 传送门：网站收藏

### 收藏与打开

复制完整的 `https://` 或 `http://` 网址。小球收起时会显示收藏邀请，点击确认保存；也可打开传送门，点左上角「收藏剪贴板」。标题默认取域名，点击卡片用默认浏览器打开。

非网址文本不触发邀请，已有链接不重复提醒。面板展开时复制的网址可在收起后提醒；气泡会超时关闭且有限流。设置 → 交互可关闭提醒。识别剪贴板不会自动访问网页；收藏后的图标和可选简介获取会联网。

### 分组、排序与删除

- 在左侧输入名称创建分组，分组右侧可重命名或删除。删除分组后链接归入默认组。
- 长按自定义分组，上下拖动调整顺序；全部和默认固定在前。
- 拖动网站卡片调整顺序，右键卡片选择目标分组。
- 分组过多时只滚动列表，收藏按钮和新建入口保持可见。
- 悬停网站卡片，点右上角删除会立即移除收藏，没有回收区；可重新收藏或从旧备份恢复。

### 图标与简介

图标优先使用内置覆盖、网站图标和缓存，必要时尝试图标服务；SANAA 等站点有附带字标。仍无法读取时显示首字母。悬停查看已有简介；新收藏的 AI 简介需要有效模型配置，失败不影响收藏。

## 4. 卷轴：提示词与版本

### 入门示例

未创建过卷轴数据的库初始化 3 条原创示例：林间亭清晨母卷轴、夜景子卷轴、社区阅读室。网格显示两个母卡片。封面是原创示意插画，不是生成效果图，也没有附带个人项目数据。

示例可以编辑和删除，删除后不自动补回。已有卷轴或已保存的空库不被覆盖。示例正文见 [examples/scrolls](../examples/scrolls/README.md)。

### 新增与编辑

卷轴 → 新增 → 填写正文、标签和可选备注，选择或粘贴预览图，再保存。预览图支持本地文件和剪贴板图片，导入时压缩。不配置 AI 也可保存、编辑和复制。

标签可记录项目、材质和氛围，上方标签栏可筛选；搜索框用于当前模块检索。

### 卡牌堆与详情

有子提示词的母卡片显示卡牌堆。第一张是母提示词封面，用左右箭头或左右拖动切换；计数标示当前版本。缺图时保留占位。悬停不再覆盖长提示词正文。

点击当前封面进入该版本的详情。母/子缩略图可切换对应内容；复制、编辑、标签和删除作用于当前展示的条目。切换图片时保留旧图，直到新图准备好。

| 操作 | 结果 |
| --- | --- |
| 复制 | 复制当前正文并显示完成反馈 |
| 编辑 | 修改正文、备注和图片等内容 |
| 扩写 / 翻译 | 用配置的 AI 接口生成结果 |
| 保存为子提示词 | 在同一母提示词下保存变体，严格两级 |
| 删除 | 首次进入确认，再点执行；点其他位置取消确认 |
| 关闭详情 | 返回列表 |

删除母提示词会连带删除子提示词。卷轴没有回收区，重要内容请先备份。

### 文档导入

「导入文件」支持识别 DOCX、PDF、TXT、Markdown、HTML、CSV、JSON、RTF 中的提示词，需配置 AI。旧 DOC 请另存为 DOCX，扫描 PDF 需先 OCR。单文件大小、文字和图片数量有上限，界面会显示降级或跳过说明。

识别会发送提取的正文，模型支持时也发送少量参考图到你填写的接口；确认内容可交给该服务后再使用。

## 5. 秘籍：快捷键速查

选择 SketchUp、Rhino 或 AutoCAD，按分类浏览或搜索命令、关键词、英文代码。234 条参考资料可离线查看。软件版本和自定义键位影响实际操作，以你的软件设置为准。

完整表：[SketchUp](shortcuts/sketchup.md) · [Rhino](shortcuts/rhino.md) · [AutoCAD](shortcuts/autocad.md)。当前不支持通过秘籍修改设计软件的键位配置。

## 6. 百宝匣：素材管理

### 建库与收集

首次选择资料库目录，创建或打开 `Musy百宝匣`。

| 入口 | 内容 |
| --- | --- |
| 导入文件 | 选择一个或多个本地文件 |
| 导入文件夹 | 递归索引文件；仅按选中的最上层目录名建一个分组，不为下级目录建分组 |
| 从剪贴板导入 | 复制的文件、文件夹或位图图片 |
| 拖入面板 / 小球 | 收集本地路径和支持的图片数据；拖到小球时显示接收气泡 |

本地文件默认引用：记录位置，不复制或移动原件。剪贴板位图保存到资料库 `clipboard/` 目录。网页拖图取决于浏览器交付的数据，并非所有网站都可直接拖入。

导入提供进度、取消、失败重试；成功记录保留。去重基于原件路径，不是视觉相似检测。

### 浏览与编辑

| 操作 | 作用 |
| --- | --- |
| 单击卡片 | 选择一个素材 |
| 圆形选择框 / Ctrl+单击 | 多选或取消单项 |
| 双击 / Enter | 系统默认应用打开原件 |
| 右键卡片 | 查看/编辑，不再有独立的查看/编辑按钮 |
| 空格 | 轻预览；输入框内不触发 |
| 拖出原件 | 将真实文件交给支持系统拖放的目标程序 |

详情可编辑名称、分组、标签、备注、来源、作者和许可备注；支持手动封面、复制路径、打开位置、重新定位。多选工具条可批量增减标签、关联项目、归组和移入回收区。回收区内可恢复或手动永久删除；移入满 30 天后自动清理，软件关闭期间到期会在下次打开资料库时补清理。外部引用原件保留，永久删除会清理库内条目、自有封面/缓存及软件保存的剪贴板原图。

### 筛选与排列

按关键词、类型、分组和标签筛选，也可查看回收区。排列方式包括最近导入、名称、最近打开、文件日期、文件大小。日期从新到旧，大小从大到小；使用导入或重新定位时记录的信息。可清除筛选，避免误以为素材丢失。

### 缩略图与预览

卡片缩略图等比铺满，边缘可能裁切。轻预览完整显示比例：滚轮或加减缩放、适应按钮恢复、左右键切换、Esc / 空格退出。可置顶参考窗口，多选两张图片可并排参考。

Rhino、CAD、SketchUp、Photoshop、Grasshopper、PowerPoint 等优先读取保存时的预览，再尝试 Windows 格式组件。没有预览时保留格式占位，仍可外部打开或手动指定封面；不执行 GH 定义，不进行完整 3D 渲染或逐页 PPT 渲染。

详见[缩略图支持](百宝匣缩略图支持.md)、[P0 使用说明](百宝匣P0使用与交付.md)和[P1 收集与复用](百宝匣P1收集与复用.md)。

## 7. 设置

- **外观**：13 套配色，经典哑光、毛玻璃、液态玻璃、牛皮纸、毛茸茸、亚麻、陶瓷 7 种质感及强度调节，多窗口同步。
- **玻璃调节**：液态玻璃支持底色浓度、质感强度和可选桌面背景模糊；保留通透高光，未提供真实桌面折射。
- **致谢与反馈**：查看开源项目与许可，打开 GitHub 问题反馈。
- **语言**：中文、English、日本語，包含收集气泡、主要状态和原生对话框。自定义标题、标签、正文、文件名不自动翻译；可加载自定义 JSON 语言包。
- **交互**：复制网址收藏邀请开关。系统减少动态效果设置会弱化部分运动。
- **模型**：兼容 `/chat/completions` 的 Base URL、API Key 和模型名。没有内置密钥。密钥存于本地浏览器存储，未加密；主进程向所填地址请求。
- **数据路径**：指定收藏与卷轴的 `musy-data.json` 备份目录，或从该文件恢复。

## 8. 备份与换电脑

1. 设置 → 数据路径，选可写目录，确认生成 `musy-data.json`。新电脑从同一页恢复；恢复替换当前收藏、分组和卷轴，请先备份。
2. 百宝匣 → 管理资料库 → 备份索引与封面，得到 `.musybox`；新电脑选择资料库后恢复。
3. 另行复制引用原文件和资料库 `clipboard/` 自有图片。迁移整个资料库并保留原素材更容易恢复路径，根目录变化时重新关联。
4. 在织梦台导出 `.musyprojects`，新电脑恢复项目关系；同时迁移对应的收藏、卷轴与原素材库，保留原条目 ID。
5. 新电脑重新填写 AI 配置及语言、外观偏好。

`.musybox` 不含原件，`musy-data.json` 不含百宝匣。只复制 exe 或这两个备份文件，不能完整迁移素材。完整说明见[数据与迁移](数据与迁移.md)。

## 9. 常见问题

**小球不见了**：检查任务栏，再次启动可唤起已有实例；多显示器环境检查原显示器位置。

**复制网址没有邀请**：确认完整 http/https 地址、提醒已开启、小球收起、链接未收藏，并等待剪贴板检查；也可手动收藏。

**找不到素材**：清除分组、类型、标签和搜索筛选；连接原硬盘或重新定位缺失文件。

**没有缩略图**：文件可能没保存预览或本机缺少组件。可在原软件保存后刷新，或指定封面；浏览索引无需安装全部设计软件。

**AI 失败**：检查接口、模型、密钥、网络和服务额度；超时、上下文长度和图片支持取决于所选服务。

**卷轴存储空间已满**：先备份，再减少或压缩预览图。含图卷轴占用 localStorage 配额，百宝匣原文件引用不共用此配额。

**会自动上传或升级吗**：当前没有自动升级或云同步。AI、图标和打开网站按操作联网；导入素材库不会自动上传原件。

## 11. 资产标签与统一检索

v0.2.1：百宝匣勾选素材后可用「批量标签」添加或移除标签，右击详情可查看并调整所属项目。织梦台选择「公共资料库」检索网站、母子卷轴和当前素材库；选择项目则限定到项目资料。支持资料类型、完整标签与多关键词筛选。原文件保持原位。操作与数据范围见[资产标签与统一索引](资产标签与统一索引.md)。
