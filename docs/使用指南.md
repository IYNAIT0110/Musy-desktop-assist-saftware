# STArra v0.3.4 使用指南

适用 Windows 10 / 11 x64。更新于 2026-10-29。默认功能顺序：星砂 → 织梦台 → 卷轴 → 百宝匣 → 传送门 → 秘籍 → 胶囊。中键小球打开星灵，右键 mini 栏打开星笺。

## 星砂 · 便签与 Markdown

星砂收好随手记下的想法，也能保存待办事项和使用文档。

## 开始使用

1. 左键小球展开功能栏，选择「星砂」。
2. 点击分类文件夹，再从左侧选择文档；已有文档默认以预览模式打开。
3. 点击正文进入编辑，点击空白处回到预览；新建时可选择「普通文本」或「待办事项」。
4. 点击标题、正文或待办输入区可收起两侧列表；点击展开按钮恢复。专注书写保留同一份草稿。

## 两种预设

- 普通文本：适合随记、会议记录和 Markdown 文档，支持多级标题、加粗、斜体、删除线、列表、引用、代码和链接。
- 待办事项：适合任务清单；预览时也能点击任务文字或勾选框完成或取消完成，状态自动保存。

「功能演示」文件夹内有两种预设样例和可用于 AI 优化的示例原稿，均可自由修改或删除。

## AI 优化

先在设置中填写自己的模型接口、API Key 和模型名称。打开文档后点击「AI 优化」，选择内置智能重点整理、自定义提示词或导入的 Skill。

内置指令会整理重点、任务、决定、时间与待确认信息。程序提供本机当前日期供模型理解“明天”等表达；仍需人工核对结果，不保证事实正确。

结果先预览，可替换原文或另存新便签；失败或取消不会直接替换。待办数量或完成状态无法保留时，只能另存为普通文本。只发送当前文档及所选指令到你配置的接口，可能产生服务费用。

## 保存与导出

编辑自动保存到本机，状态异常时先处理再退出。点击「导出 .md」导出当前最新内容；普通文本保留 Markdown，待办保存为勾选清单。单篇导出不含分类、编辑历史和全部偏好，整库备份使用「胶囊」。

Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+K 链接，Ctrl+Alt+1–6 标题，Ctrl+Z 撤销，Ctrl+S 提交保存。

## 内置文档

「使用文档」文件夹包含各功能说明、工作流和产品故事。v0.3.0 仅补充一次，不覆盖已有文档；删除后不会在重启时强行补回。

## 织梦台 · 项目关联

织梦台将网站、卷轴和当前百宝匣资料关联为项目，帮助你回到正在进行的工作。

1. 打开织梦台，点击「新建项目」，填写名称、项目文件夹及说明。
2. 在顶部项目胶囊左键选择当前项目；右键或开关控制自动关联。
3. 开启后，通过小球快捷保存的新资料默认关联当前项目；保存界面可临时选择公共库。
4. 已有网站、卷轴、百宝匣素材可通过「关联项目」加入，同一份资料可以关联多个项目。
5. 在织梦台按类型、标签、关键词和项目筛选；「继续工作」记录近期打开、复制过的关联资料。

归档仅收起项目，不删除原件。关联不移动原文件，也不会自动复制完整项目目录。

旧的关联备份只包含项目、关系与检索摘要；要带走原件，请使用「胶囊」。跨软件自动追踪依赖、完整版本时间线与 Agent 接力属于后续方向。

## 卷轴 · 提示词与预览图

卷轴保存提示词、标签、预览图与母子关系，适合整理方案变体。

1. 点击「新增」填写文字、标签，可添加预览图；也可从文档导入。
2. 为母卷轴添加子提示词，记录同一方向的不同时间、材料或构图。
3. 有子卷轴时，拖动卡牌或点击箭头切换母、子预览图；点击卡片打开详情。
4. 在详情复制、编辑或删除；删除确认在点击其他区域后收回。
5. 已配置模型时，可用扩写或翻译辅助整理；发送内容由当前操作决定。

默认只有三个原创入门示例及其示意插画，不包含开发者实际项目、生成效果图或私人提示词。已有卷轴不会被预置覆盖。

预览图占用浏览器存储配额，图片过大时应压缩。胶囊会携带应用中的卷轴记录与内嵌预览图；不要只备份项目文件夹。

## 百宝匣 · 素材收集与复用

首次使用点击「选择或创建资料库」；以后可在「更多操作 → 管理资料库」中切换目录。百宝匣默认引用原文件，索引和封面保存在资料库中。

## 收集

- 点击「＋ 添加」选择导入文件、文件夹或剪贴板内容；菜单内可切换「本次仅存公共库」，启用后显示提示；也可在列表内按 Ctrl+V，或把文件、文件夹、图片拖入。
- 文件夹导入按最外层目录名称归组，内部子目录不再逐级建立分组。
- 剪贴板图片会保存为资料库内的自有文件；外部导入文件仍引用原件。

导入成功后直接更新素材列表，不显示完成提示栏；只有导入失败、中断或项目关联失败时才弹窗说明。导入期间可在左上角「正在导入」菜单中取消。

## 浏览与整理

顶部显示当前分组与素材数量；点击「筛选与排序」展开类型、标签和排序选项，收起后仍显示已启用的条件。选中素材后可预览或关联项目，点击「整理」展开标签与归组；「更多」提供全选、取消选择和移入回收区等操作。标题相似不代表文件相同，原件位置改变时需重新定位。

双击用外部软件打开，右击卡片查看或编辑，空格轻预览，滚轮缩放图片；可选择图片并排参考，拖出原件到其他软件。选择圆钮在悬停、键盘聚焦或已有选择时显示。需要重新读取封面时，使用「更多操作 → 刷新」。

Rhino、CAD、SketchUp、PSD、PPT 等读取可用的保存预览或系统缩略图，不是完整建模或编辑器；没有内嵌预览的文件可手动设置封面。第三方软件是否安装也影响预览能力。

## 回收区与备份

回收区可恢复或手动永久删除；满 30 天后自动清理，关闭期间到期会在下次打开时补清理。永久删除会清理对应记录、自有图片与缓存，外部引用原件保留。

旧索引备份不含全部外部原件；请用「胶囊」勾选引用原件和资料库一起备份。只扫描当前连接资料库，其他资料库需要添加目录。

## 传送门 · 网站收藏

传送门保存网站链接、收藏分组和说明，内置 64 个公开设计与工作网站。

1. 复制网址后，点击「收藏剪贴板」，选择分组。
2. 小球收起时，检测到未收藏的新网址可弹出收藏邀请；设置中可关闭。
3. 用搜索查找网站，点击卡片打开系统浏览器。
4. 收藏分组支持调整名称和顺序；项目收集开关开启时，可把新链接关联到当前项目。

图标会尝试从网站与可用图标来源获取。网络、网站限制或图标缺失可能导致回退显示。收藏记录保存在本机，胶囊可统一备份。

打开链接或抓取图标需要联网；内置网站不表示官方合作或背书。

## 秘籍 · 软件快捷键参考

秘籍提供 SketchUp、Rhino 与 AutoCAD 的离线快捷键参考。

选择软件和分类，再输入关键词查找命令与键位，适合工作时快速回忆操作。

快捷键可能受软件版本、操作系统、语言、个人设置和插件影响，应以你的实际配置为准。本功能不安装或控制这些软件，也不代表全局快捷键已经接入。

参考资料随程序提供，无需单独迁移；个人外观与应用偏好可以使用胶囊备份。

## 胶囊 · 备份与换机继续

胶囊把应用记录与选定原文件复制为一个可整体携带的 .starrapack 文件夹。它是个人备份与迁移入口，不是对客户的纯项目交付包。

## 完整备份

1. 打开胶囊，选择「完整备份」。
2. 确认项目文件夹、百宝匣引用原件、已配置数据路径；未连接资料库用「添加其他文件夹」加入。
3. 决定是否包含模型 API Key，默认会包含。备份可能含私人内容和密钥，请妥善保管。
4. 点击「扫描并预览」核对目录、文件数量、容量和缺失提示。缺失或无权限文件可先修复并重扫，或明确确认跳过。
5. 点击「选择位置并打包」，建议选择另一块磁盘。不要保存到备份源目录内部。

输出为 STArra-日期-编号.starrapack 文件夹，无需解压。必须整体复制，不能只复制清单或 state.json。

## 按范围导出

支持最近修改、指定项目、日期范围；指定项目还可叠加起止日期。日期以原文件最后修改时间为准，包含起止日，使用本机时间。

所有模式始终包含完整应用记录和当前资料库自有文件。范围只筛选原文件，未选原件的记录仍保留，换机后可能需要重新定位。仅扫描当前连接资料库和选定目录；链接与联接跳过并提示。

即使选择单个项目，仍可能包含其他应用记录与密钥，不应直接发给客户或公开上传。

## 在另一台电脑恢复

1. 安装 STArra，把整个 .starrapack 文件夹复制到新电脑。
2. 打开胶囊，点击「从备份恢复…」，选择备份文件夹。
3. 确认后选择新的工作目录位置。程序校验文件、复制原件并重建已打包目录的路径。
4. 恢复完成后自动重启，使用独立新配置继续。当前配置和原文件保留。

Rhino、CAD、Office 等第三方软件和授权需要另行安装。缺失或被排除的原件不会自动补齐。恢复不是云同步，不支持多人冲突合并。

文件复制后使用 SHA-256 校验；源文件在扫描后变化、磁盘不足或校验失败会停止，不会把未完成结果标成成功。

## 星笺 · 今日待办入口

右键小球打开 mini 功能栏，星芒纸笺图标对应「星笺」。

星笺跟随应用的中文、英语和日语设置即时切换，包含日期星期、任务编辑、提示及轮盘说明；已打开的独立窗口同步更新。用户填写的任务、备注和文件夹名称保留原文。

任务区右侧使用可展开时间尺替代灰色滚动条。靠近时刻度局部放大，并预览时间及附近任务；任务位置以对应颜色标记。单击时间尺在所指时间打开新任务编辑框，按 5 分钟取整；拖动时预览，松手跳转。在尺上滚动滚轮仍可浏览页面。聚焦后上下键、Page Up/Down、Home/End 可导航，Enter/空格在选定时间创建任务，Esc 取消拖动。时间尺在空白日也可创建任务；减少动态效果设置会关闭刻度过渡动画。

星笺按任务节点展示一天：顶部一周日期栏可切换日期，圆点表示当天任务。彩色节点按开始时间排列，显示起止时间、时长和完成圆钮，空闲时段压缩为间隔提示。点击「＋ 新任务」、空闲间隔或日程末尾入口添加任务，点击节点编辑，完成可撤销。无明确时间的任务进入「待安排」，此前未完成任务不会自动推到今天。

任务区保持紧凑节点总览，缩放旋钮和时间尺旁的实线已移除。日期通过一周日期栏切换，原右上角重复的日期按钮已移除。

「星砂来源」默认关闭，选择文件夹后同步未完成待办和 Markdown 勾选项；内置文档及演示排除。时间按源便签更新时间和电脑时区解析，不猜测不明确的时间。任务去重，手动编辑和完成状态保留，来源删除不会删除任务。

「AI 提取」使用自己配置的模型，只在点击时调用，候选需确认后创建。模型会对照已有任务识别同义重复项，确认后合并来源；同一时间的明确重复任务也会由程序去重，并保留已完成状态。支持取消；日期和内容仍需核对。

节点保留完整的起止时间和时长文字，较长任务留出更多空间；重叠日程会明确提示。长按任务后上下拖动可移动时段，拖动上下边缘可修改开始或结束时间，以 5 分钟为步长。调整时直接显示新的时间。关联任务的时间与完成状态在星笺和星砂之间双向同步。

AI 提取结果统一放进来源文件夹下的「AI星流」待办便签，按日期和时间排序。以后重复提取会复用同一份文件，只补充新任务，保留已有任务及其完成状态；AI星流本身不再参与 AI 提取。旧版追加到正文中的程序生成任务会迁移到这里，原文和人工备注保留。

数据保存在当前配置目录的 today.json 和快照，跨文件同步中断会在下次读取时恢复，胶囊备份包含星笺。发生并行编辑冲突时保留草稿，可另存副本或加载最新版本。当前不支持系统通知、外部日历；星轨、星镜仍为 UI 预览。

## 设置与外观

在系统按钮中打开设置，可选择模型配置、数据路径、外观、语言、交互，以及致谢与问题反馈。

## 外观

支持 13 套配色及 8 种材质：经典哑光、毛玻璃、液态玻璃、磨砂颗粒、牛皮纸、毛茸茸、亚麻与陶瓷。配色与材质分别保存，质感强度可调。

液态玻璃保留底色、边缘高光与可选系统背景模糊；真实桌面连续折射没有启用。磨砂颗粒是静态纹理，不使用动态渐变。

右下角「恢复默认外观」只恢复外观，不删除收藏、文档、项目或素材。云白主题使用深色字标。

## 语言与模型

内置中文、英语与日语。API 接口由你选择并保存于本机；请只使用可信服务，避免把含密钥的胶囊发到公开渠道。

## 导航

默认顺序：星砂、织梦台、卷轴、百宝匣、传送门、秘籍、胶囊。可拖动排序，Esc 取消；键盘聚焦后 Alt+左右键移动，保存过的个人顺序会保留。

右键小球呼出 mini 栏，三个独立按钮直径 52px，跟随功能栏材质；再次右键或 Esc 收回，靠近屏幕边缘会翻转。当前只有 UI 预览。

## 工作流 · 组织、创作、继续

STArra 的实际可用流程：创建项目 → 收集资料 → 整理与记录 → 预览和复用 → 胶囊备份 → 换电脑继续。

## 1. 建立工作上下文

在织梦台创建项目，关联实际项目文件夹；顶部项目胶囊选择当前项目，按需要开启自动关联。

## 2. 收集与组织

在传送门收藏网页，在卷轴整理母子提示词，在百宝匣导入参考文件或剪贴板图片。通过小球快捷保存的新资料可默认关联当前项目；已有资料手动关联。

## 3. 记录与创作

用星砂的普通文本保存设计记录，待办事项列出行动项。需要时配置模型并使用 AI 优化，先核对再应用。Rhino、CAD、Photoshop 等仍在各自软件中使用，STArra 不替代原生编辑器。

## 4. 找回并复用

在织梦台按项目、类型、标签、关键词定位资料；百宝匣轻预览、并排参考，拖出原件。项目关联只记录关系，不移动源文件。

## 5. 用胶囊保存工作

离开当前电脑前，打开「胶囊」。做灾难恢复备份时选择完整备份；只想带走最近原件时选最近修改，或指定项目并叠加日期范围。

核对项目目录、引用原件、数据路径和附加资料库，决定是否包含密钥，扫描清单后处理缺失提示。选择源目录以外、最好另一块磁盘的保存位置，生成 .starrapack 文件夹。

范围只筛原文件；完整应用记录和当前资料库自有文件始终包含。因此胶囊适合个人备份迁移，不是可以直接发给客户的脱敏交付包。

## 6. 换电脑继续

在新电脑安装 STArra，复制整个备份文件夹，从胶囊执行恢复，选择新的工作目录。校验与复制成功后自动重启，并重建已打包路径。当前旧配置保留，外部软件与授权另行安装。

## 7. 定期检查

确认原件磁盘仍可访问，给重要阶段做独立备份。回收区的自有图片可能在 30 天后被清理，不应把回收区当归档。未选文件、缺失原件和断开的资料库需另外处理。

## 当前边界

mini 栏星轨、星镜仅 UI，点睛笔仍是占位。云同步、自动版本时间线、跨软件依赖追踪、自动 Agent 接力和脱敏交付包属于未来方向，不代表本版已实现。

## 品牌故事

每一个伟大的设计，都始于一个微小的闪光。

它可能是一张随手绘制的草图，一段突然出现的灵感，一次模型的调整，或是一场讨论中尚未成形的想法。

随着项目不断推进，这些微小的闪光逐渐变成图纸、模型、图像、文档与无数个设计版本。

然而，创作的过程并不总是连续的。

我们的灵感散落在不同的软件中，文件保存在不同的设备上，重要的设计决策遗留在聊天记录和会议里。一个设计版本为什么诞生、又为什么被取代，往往随着时间慢慢消失。

如今，人工智能带来了更多创作的可能。不同的 Agent 可以帮助我们绘图、建模、分析和生成方案，但它们之间依然存在一道道看不见的边界。

工具越来越强大，创作却可能变得更加碎片化。

我们开始思考：

如果更换设备、更换工具，甚至更换创作者，都不意味着重新开始。

这就是 STArra 诞生的初衷。

我们把创作过程想象成一片不断生长的星空。

**每一个想法，都是一颗星。**

文件、版本、决策和创作工具之间的关系，如同星星之间的连线。随着项目发展，它们逐渐形成属于自己的星座。

STArra 让这些关系变得清晰、可追溯、可延续。

它不试图代替设计师，也不要求所有创作都发生在同一款软件中。

它希望成为连接不同工具、不同设备、不同智能体与不同创作者的工作空间，让创造力自由流动，而不再被割裂的信息和重复劳动束缚。

## STArra星灵 · 工具调用助手

鼠标中键单击小球，打开独立对话窗口，再次中键收起；左键展开功能栏和右键 mini 保留原有操作。Enter 发送，Shift＋Enter 换行，Esc 收起对话。右侧时间尺按用户提问先后排列，悬停预览发送时间及原文，点击或拖动回到对应轮次，在尺上滚动滚轮浏览对话。

## 模型负责规划，软件执行工具

星灵把可用工具开放给模型，模型可连续查询、读取、创建、修改、搜索和生成文件。每一步真实结果回传模型，模型据此继续处理或追问；普通回复无需返回固定意图 JSON，也不使用关键词规则抢占意图。

模型配置沿用设置中的接口、模型和密钥，接口需支持兼容 Chat Completions 的 Function Calling（tools/tool_calls）。如果接口不接受工具调用，会明确提示；模型的网页产品具有某项能力不代表其聊天 API 已包含相同工具。本地资料只在模型调用相应工具后按需读取，并作为工具结果发送至配置的模型服务；不自动上传整个资料库或发送设置密钥。

## 可以尝试

- 「明天下午三点开会，持续一小时」：模型解析后创建任务，程序校验并同步星笺与对应文件夹的 AI星流。默认使用「随手记」，用户明确指定已有文件夹时使用该文件夹。
- 「把本月所有待办按日期整理成 Word」：模型自行计算日期范围，查询并按需分页读取真实任务，整理内容，调用生成文件工具，返回可打开和另存的文件卡片。
- 「把刚才的报告转换成 PDF」：会话保留真实工具结果和文件 ID，模型可以读取原文件内容继续转换或修订。
- 「查询下周未完成任务，把会议改到周五下午三点」：模型先读取任务及版本，再调用修改工具；任务时间和完成状态继续双向同步。版本已变化时工具返回冲突，模型应重新读取。
- 「读取工作文件夹的方案笔记，整理成一篇新便签」：模型可搜索、分页读取、创建或修改普通文本便签。关联待办通过任务工具修改。
- 「查找本地庭院资料」：搜索便签、收藏网站和百宝匣素材索引，不扫描整台电脑；结果卡片可打开对应内容。
- 「联网搜索木结构建筑案例，整理参考清单」：联网搜索使用右上角配置的 Tavily Key，只发送搜索词并返回真实来源链接，可能产生模型和搜索服务费用。未配置时提供配置入口和浏览器搜索按钮，不伪造结果。

## 文件与执行反馈

支持 DOCX、XLSX、PDF、MD、TXT、CSV、JSON。Word/PDF 可包含标题、段落、列表和简单表格；Excel/CSV 使用表格数据。生成文件存放在当前应用数据目录中，只有应用生成的文件可以通过文件工具读取，模型不能指定任意磁盘路径或执行代码。使用卡片「打开文件」或「另存为」取出结果。生成文件暂不包含在胶囊备份中，需要长期保留或迁移时请另存。

对话中可展开「执行步骤」，查看工具执行是否完成。复杂任务允许多步调用和工具参数纠错，分页结果也会回传模型继续读取。查询结果卡片最多展示 200 项参考任务，不影响模型通过分页获取更多数据生成报告。

单次执行最长 180 秒，受轮次和工具调用次数限制。停止、超时或网络中断时，已完成的任务、便签和文件保留并显示；可用「继续处理」从保留的工具结果继续，避免重复写入。超过全部步骤预算或会话已有后续操作时，请发送新消息继续。

仅本次新建的任务可「撤销本次创建」，星砂与星笺一起撤销；用户已修改过的任务不会被撤销覆盖。软件没有开放任意删除、命令执行或任意文件读取工具。会话只保留到本次应用退出，生成文件持续保存在本机；中英日切换即时更新界面，用户原文与模型历史回复保持原文。胶囊关闭密钥备份选项时不导出模型及搜索密钥。

## 外部 Agent：共享资料与成果

在设置中打开 **外部 Agent**。STArra 必须保持运行；外部 Agent 所在电脑需安装 Node.js。

1. 开启「允许外部 Agent 连接」。默认只读，可查询星砂、星笺、项目及素材索引。
2. 如需新建、修改、删除或执行应用操作，再开启「允许新建和修改（每次询问）」。外部 Agent 每次提交的修改清单都需要你确认；开关不是永久免确认授权。
3. 添加授权文件夹，选择只读或读写。项目已经配置的路径不会自动获得文件访问权限，需要另外授权。
4. 展开「连接配置」，复制 MCP 配置，加入外部 Agent 的 MCP 设置。如果已有 mcpServers，请只合并其中的 starra 条目。
5. 重启或重新连接外部 Agent 的 MCP。可将 STARRA_AGENT_NAME 改为容易辨认的名称，用于成果与日志来源标记。

可以这样向外部 Agent 下达任务：

> 读取 STArra 中的项目背景，为这个项目设计一套首页，保存在已授权目录。完成后调用 register_artifact，把文件关联到该项目，并填写成果说明。

> 查询今天的任务，把设计评审调整到下午四点，并同步 STArra。

## 文件与成果

- Agent 先调用 list_projects、list_roots 获取真实 ID；文件操作使用 rootId + relativePath。
- 使用 write_file 新建或修改的文件会自动登记。由 Agent 自己写入磁盘的大文件，应使用 register_artifact 登记。
- 关联项目的成果在织梦台对应项目中显示。设置中可查看全部成果，点击「打开」或「所在文件夹」检查真实文件。
- 已登记文件的修改时间、大小及缺失状态约每 2.5 秒刷新。文件改名或移动后，应重新登记新路径；旧路径标记失效。
- write_file/read_file 上限 4 MiB，支持 UTF-8 和 base64。创建子目录使用 create_directory；父目录必须存在。大文件由 Agent 原有文件能力处理后登记，不受登记体积限制。
- 覆盖文件需要 read_file 返回的 sha256；内容已变化时会拒绝覆盖，Agent 应重新读取。旧文件保存在当前数据目录的 external-agent/revisions 下，`.json` 记录原路径，配对 `.bin` 是旧文件内容。恢复时先关闭 Agent 访问并自行确认所需版本。

## 访问与同步

便签、任务通过应用工具操作，界面自动刷新，任务与 AI 星流维持关联。Agent 不需要直接修改内部数据文件。卷轴、收藏、便签、任务、项目和素材的正常删除操作也可通过工具完成，但必须确认。终端执行、密钥读取、外部 Agent 自行授权或绕过确认的入口不开放。

取消目录授权会停止访问该目录；关闭连接开关会停止所有外部 Agent 调用。只读模式仍可读取应用资料。来源名称由客户端提供，用于辨认操作，不能用来判断连接者的可信身份。

连接配置指向本机连接文件，只能供这台电脑上的 Agent 使用；不要把连接文件或令牌发给他人。端口每次启动自动生成，stdio 桥会读取最新连接，无需每次重配。密钥更新后，直接 HTTP 客户端需更新令牌；使用本机桥的客户端会自动读取最新令牌。若要彻底停止它们访问，应关闭连接或移除其本机配置。

胶囊备份目前不包含外部授权、成果索引、操作记录与覆盖恢复副本。成果原文件保留在授权目录内，迁移后重新授权和登记。

## 接口

调用 list_operations 获取当前完整操作目录、参数格式和确认要求。除原有查询、文件、任务工具外，app_ 开头的操作覆盖星砂、卷轴、传送门、织梦台、百宝匣、星笺、秘籍、点睛笔、外观、语言、功能栏排列、模型配置和胶囊备份。只读时不枚举写工具。

也可向连接文件中的本地 `/mcp` 端点发送 MCP JSON-RPC POST，请求头为 `Content-Type: application/json` 和 `Authorization: Bearer <token>`。此入口仅限本机，不是远程服务；接入无需模型密钥，模型调用由外部 Agent 自行负责。

## 一次确认一份修改清单

只读查询直接返回。新建、修改、删除及会执行应用动作的工具，会弹出独立的确认窗口，显示 Agent 来源标签、本次操作、参数和可读取到的当前目标。点击「确认并执行」只批准当前清单；拒绝、关闭、两分钟未响应或客户端断开，都不会启动待确认操作。已经开始执行的操作可能已经完成，Agent 应根据结果检查，不应盲目重试。

多步工作使用 batch_operations：每项指定 tool 和 JSON 字符串 argumentsJson，一份最多 20 项，只询问一次。全部参数会先校验，再申请确认；顺序执行遇到错误即停止，并返回 completed、error 和 stoppedAt。这不是整体事务，已完成的部分不会自动回滚。资料在等待确认期间发生变化会拒绝执行，Agent 应重新读取后再提交新清单。

胶囊和百宝匣恢复本身已有完整的原生确认，会复用该确认；恢复必须单独调用，不能夹在其他修改的批量清单中。文件选择对话框仍需要用户选择目标位置。

## 图片与提示词保存到卷轴

外部 Agent 生成图片后调用 save_prompt，提供 text、tags、note（可含模型、负面提示词、种子、尺寸等）、imageRootId、imageRelativePath；可指定 projectId 和 parentId。更新已有卷轴还需 id 和读取到的 expectedRevision。

确认后，STArra 将原始图片复制到当前数据目录的 prompt-media，并生成紧凑预览；提示词、参数、预览和原图路径一起保存到卷轴。源文件可在授权目录内，支持 PNG/JPEG/WebP/GIF，原图上限 24 MiB。源文件之后被移动或删除不会影响保存的副本。卷轴配额不足会返回失败，不能把失败当作已经保存。

卷轴托管原图会进入胶囊备份，恢复时复制到新配置的 prompt-media 并修正路径；普通网站/卷轴 JSON 导出携带预览与原路径，不包含原图文件本身。

可以对 Agent 说：

> 生成这张图片后，把提示词、负面提示词、模型和种子一起保存到卷轴，并关联当前项目；把这几步合并成一份清单让我确认。


## MCP 小球反馈（v0.3.2）

外部 Agent 连接、执行、等待确认和返回结果时，小球会显示状态并弹出提示气泡。普通提示停留 8 秒，失败 12 秒，等待确认 15 秒；气泡与小球居中，拖动时跟随，靠边自动换边。拖动不延长停留时间。

在「设置 → 外观 → MCP 小球动画」选择流光光环或双星轨道。流光光环每次新调用会轻微放大并提亮，波峰转一圈后回落，约 1.3 秒；快速返回也会完成，等待确认恢复同一调用不重复播放。光圈大小和粗细可调并实时保存，系统减少动态效果时保持静态提示。反馈不改变权限、工具结果或修改确认要求。

## 织梦台文件看板（v0.3.3）

选择项目目录后，在「文件看板」确认扫描。可按类型、日期与状态筛选，切换卡片、列表、时间和圆点关系图；人工确认版本组、工作版本及导出/引用/参考/分支关系。建立关系的目标选择提供缩略图与路径，方便辨认。

选择文件可主动保存真实内容快照或项目节点，历史可预览、并排参考及恢复为副本。扫描不更改原件，当前需手动刷新、保存快照，不会自动补回覆盖前的文件。浏览其他项目不改变自动收集目标。通过胶囊迁移看板、关系和快照；旧关联备份不含这些数据。

## 顶部星岛与任务胶囊（v0.3.4）

收起功能栏，将小球拖到屏幕顶部附近松手，连续变为顶部中央的星岛。左键开合导航，右键呼出横排 mini 栏，中键打开助手。收起状态向下拖回小球；重启后回到自由小球。

右键 mini 栏的星笺显示当天任务，一项一个同宽胶囊气泡，间隔 8px；点击任务完成或取消完成，点击刘海隐藏气泡。无「今日待办」标题、日期和 X。星笺的时间用应用内小时/分钟下拉菜单选择；已保存任务继续保留。

顶栏搜索按钮或 Ctrl+K 打开全局搜索。星轨、星镜仍为 UI 入口；连续桌面折射未启用。
