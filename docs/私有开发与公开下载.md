## 本地防误推

公开仓库的远程名称为 `public`，其 push URL 禁用，只保留读取。已确认私有的新仓库设为 `origin` 和默认推送目标；现有 `main` 提交历史迁移过去，历史公开版本与标签继续保留在原公开仓库。

`.githooks/pre-push` 会拦截向公开仓库和其他地址推送源码。新克隆须配置 `git config core.hooksPath .githooks`。该本地保护不能代替远程可见性检查，不应绕过。

## 构建与发布

工作流只允许在实际为私有的仓库运行，权限为读取源码；构建后保存私人 Actions 产物，不自动创建 Release。

将来公开下载只上传经确认的二进制、SHA-256 和用户文档。不要将源码、Git 历史、私人 CI 日志或开发资料包同步到公开仓库；公开 Release 的自动源码压缩包仅包含公开仓库自身的内容。

私人仓库若需要自动向公开仓库发布，后续单独设计并授权对应发布凭据；目前不新增跨仓库令牌或权限。

## 历史与许可

v0.2.0 的已有公开许可和第三方声明保留。私人开发不收回已公开副本，也不移除第三方许可。当前 Electron 成品仍可被技术分析，私有仓库不等于安装包无法提取代码。
