# 织梦台文件看板 · v0.3.3 开发交付与后续优先级

日期：2026-10-29。本文记录当前完成范围；原始调研中的设想不等于已交付能力。

## 已完成

| 范围 | v0.3.3 行为 |
| --- | --- |
| 项目文件 | 确认范围后只读扫描，跳过链接和临时目录；取消、进度、缺失状态 |
| 文件呈现 | 缩略图/格式图标、卡片/列表、类型/日期/状态筛选、排序、多选 |
| 版本 | 相同格式人工归组、候选提示、展开、拆出、撤销，明确当前工作版本 |
| 时间 | 磁盘修改时间分组，与首次发现、快照和项目节点时间区分 |
| 关系 | 圆点细线图，人工确认导出、引用、参考、分支，保存端点依据与变化核对提示 |
| 选择关系目标 | 缩略图、文件名、路径、搜索、键盘操作、选中预览；不支持预览时显示格式 |
| 历史 | 内容快照、SHA-256、项目节点、容量限制、预览、并排参考、恢复副本 |
| 安全与恢复 | 不覆盖原件，保存中变化/取消不冒报成功，受引用快照保护，索引损坏副本恢复 |
| 项目上下文 | 浏览项目不改变全局收集目标，显式指定工作项目 |
| 迁移 | 胶囊包含看板元数据和快照，恢复已打包路径；旧关联备份范围不扩大 |

## 当前操作顺序

选择项目目录 → 确认扫描 → 搜索/筛选文件 → 确认版本组与工作版本 → 确认文件关系 → 在原软件保存 → 保存快照/项目节点 → 修改后刷新并核对变化 → 胶囊备份到独立位置。

容量边界：每项目 12,000 条文件；关系图最多展示 180 个文件；快照默认 5 GB、可调 1–100 GB，单文件最多 2 GB、每次最多 60 个。大项目应先筛选和缩小扫描范围。

## 后续顺序

| 优先级 | 工作 | 验收方向 |
| --- | --- | --- |
| P1-1 | 收集真实项目使用反馈，完善大项目筛选、缺失文件定位与识别 | 不误认文件，不把磁盘修改时间解释为创作日期 |
| P1-2 | 项目概览、任务、成果分区与关联资料批量整理 | 继续工作入口清楚，浏览与收集状态一致，取消不写入 |
| P1-3 | 针对已选项目的增量刷新与明确的快照提醒 | 可暂停、有状态，不扫描整个电脑、不自动无限复制 |
| P2-1 | 按格式逐步增加真实依赖读取 | 每种格式明确支持范围、来源与准确率；区分解析结果和人工确认 |
| P2-2 | 更细的历史管理与备份完整性提示 | 引用保护、容量与恢复路径清楚；不删除用户未授权的内容 |
| P3 | 几何/参数差异、团队协作、云端同步、Agent 自动接力 | 另行定义授权、冲突、成本和恢复策略后开发 |

这些优先级是开发顺序，不承诺完成日期。自动依赖、自动历史和云协作均不包含在 v0.3.3 中。

## 验证

- 225 项回归测试与前后端类型检查。
- 隔离项目界面验证：目录扫描、版本组、三种视图、关系与快照、项目浏览/收集分离、中文/英文、云白主题、关系缩略图和格式占位。
