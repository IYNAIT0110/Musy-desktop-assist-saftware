# 资产标签、项目关联与统一索引

适用：v0.2.2 · Windows 10 / 11 x64 · 更新于 2026-10-27。

## 推荐整理顺序

1. 在百宝匣导入素材，保留原文件的位置。
2. 勾选一个或多个素材，点击「批量标签」，选择添加或移除，输入标签后保存。支持中英文逗号、分号和换行分隔。
3. 点击「关联项目」，选择一个或多个项目。同一份资料可以服务多个项目。
4. 打开织梦台：选项目搜索该项目的资料；选「公共资料库」则检索全部可读取的网站、母子卷轴和当前百宝匣素材。

## 标签规则

批量添加保留已有标签；批量移除只删除指定标签。全半角、前后空格和大小写统一用于去重，首个标签的显示拼写保留。每个标签最多 80 字符，每份素材最多 100 个标签。

本批编辑全部成功才保存。如果所选条目已删除、进入回收区、超出标签数量限制或写入失败，不会只改一部分。编辑期间切换资料库会拒绝原选择的写入，请重新选择条目。

右击素材打开详情也可修改单份素材的标签，并查看、调整所属项目。批量工具栏的「关联项目」会显示关联项目数量；部分资料已关联时，项目选择页显示「部分关联」。

## 统一检索

织梦台「公共资料库」显示全部可读取的资料，支持「未关联项目」筛选。项目页只显示与该项目关联的资料，并保留「继续工作」。

可按资料类型和标签筛选，点击条目的标签也能筛选。搜索支持名称、网址、素材路径、卷轴正文、备注、素材作者、授权备注和项目名称。多个空格分隔的关键词需要同时匹配；标签筛选按完整标签匹配。网站沿用原分组，未增加独立的网站标签编辑器。

条目展示所属项目，可直接调整关联。移除一个项目关系不会影响其他项目，也不会删除原资料。

索引在资料变化时更新，提供刷新按钮。素材以 500 条一页读取，校验资料库身份和索引版本；读取中途发生变化会重新读取，避免混入其他资料库的数据。普通结果先显示 60 条，可加载更多。

## 数据与边界

- 网站、卷轴沿用原 ID；素材使用「资料库 ID + 素材 ID」。同名、同路径或相同内容不会被此索引擅自合并。
- 源资料库仍是资料内容的保存位置。统一索引在内存中重建，不再持久化一份图片、原文件或完整卷轴正文副本。
- 标签仍随百宝匣资料库保存和备份；项目关系仍随项目备份保存，不能互相代替。
- 当前只索引已连接的百宝匣。其他库中已有关联保留在项目页并标注未连接；没有关联的离线库文件不在搜索范围内。
- 源条目删除或移入回收区后，公共搜索不再显示；项目页保留原关联和当时的检索摘要，待源条目恢复或手动取消关联。离线摘要可能不是最新内容。
- 索引不逐个打开或解析专业文件。磁盘原件是否存在在实际打开时由百宝匣再次检查；可读取条目不等于磁盘原件一定可用。
- 尚未包括文件内容全文解析、OCR、跨设备同步、专业文件版本身份和文件内部依赖分析。

## 验证范围

自动测试覆盖标签规范化、增减保留、批量失败不局部保存、重启持久化、分页完整性、索引版本失效、多项目与多库身份、实时元数据优先、断开引用和联合筛选。界面外观由用户手动验收。
