# 织梦台文件看板 · v0.3.3

v0.3.3 在 v0.3.2 基础上新增文件看板。项目目录看板和原有「关联资料」是两个范围：前者读取目录里的实际文件，后者保留网站、卷轴、百宝匣与 Agent 成果入口。

## 开始

1. 进入织梦台，在项目编辑中选择文件夹。
2. 打开「文件看板」，点击「扫描 / 刷新目录」，确认范围后读取。扫描不移动、重命名或删除原件。
3. 跳过链接、临时文件、版本控制目录、node_modules、开发临时目录和旧备份包。每项目最多 12,000 个条目，超出时缩小范围。
4. 文件变化后手动刷新；当前不监控整个电脑，也不会自动保存每次编辑。

## 三种视图

- 文件：真实缩略图或类型占位，支持卡片/列表、类型/状态/修改日期筛选及修改时间/名称/大小排序。「日期筛选与显示方式」包含额外选项。
- 时间：按磁盘最后修改日期归组，另列出保存的一组项目节点。首次发现、磁盘修改与快照时间分别显示，不冒充创作日期。
- 关系：圆点表示文件、细线表示关系、名称显示在旁边。选中圆点聚焦，查看直接关联、两层或全项目；拖动空白平移、滚轮缩放、拖动圆点排布。节点键盘可达，Enter/空格选择、方向键调整。每次最多展示 180 个文件，可先搜索缩小范围。

已确认的同一版本组在图谱中用虚线相连，仅表示同组，不冒认版本先后；方向和含义通过点击关系查看。

## 选择与版本

单击卡片查看详情，双击外部打开，空格预览，右键操作。勾选圆形选择框或按住 Ctrl 点击可多选。选择两个文件可并排参考。

选择相同扩展名的文件，点击「归为同一版本组」。文件仍保留原位置；卡片版本数量可展开。相近名称只提示候选，确认前不归组。平行方案请使用分支关系，不强排成前后版本。错误归组可拆出或撤销。

详情可以指定当前工作版本，它与最新修改、确认稿、交付稿分开。刷新检测到文件大小或修改时间变化后，确认/交付标记退回工作稿，避免沿用旧状态。

图片和部分设计格式复用嵌入预览与 Windows 缩略图服务，无预览时显示扩展名，可用原软件打开。小文本类文件提供纯文本预览，不执行内容。并排查看属于视觉参考，不是模型几何、CAD 图元或参数的语义差异比较。

## 建立关系

在详情或关系图下方点击「建立关系」，搜索并选择目标，再注明类型。目标列表显示缩略图、文件名和路径，选中后保留预览；无缩略图时显示格式图标。来源也提供预览，选择来源快照后可核对对应版本。

关系类型：

- 导出 / 生成到：模型 → 图纸、图纸 → PDF。
- 引用了：使用方 → 被引用方。
- 设计参考到：参考资料 → 使用它的设计。
- 分支为：原方案 → 平行方案。

关系标为用户确认；可选择保存过的来源快照，或记录建立关系时的磁盘状态。点击细线查看含义和方向。来源大小或修改时间变化后提醒「上游已有变化，请核对」，不直接判定产出错误，也不自动修改下游。

## 快照与项目节点

选择 1–60 个文件保存快照，或命名保存项目节点。快照保存真实内容并记录 SHA-256；文件在保存过程中变化、取消或写盘失败，不生成成功历史。多文件按顺序读取，不等于设计软件的原子保存，操作前先在原软件保存。

默认全局快照额度 5 GB，可调至 1–100 GB；单文件最多 2 GB。达到上限后停止，不自动删除历史。

文件详情中可预览快照、并排查看、恢复为副本或删除未引用的快照。恢复只写入不存在的新路径，拒绝覆盖已有文件。关系/项目节点使用中的快照受保护；移除节点保留快照，之后可单独管理。

没有保存过的覆盖历史无法补回。磁盘提供稳定文件身份时可追踪改名/移动；无法确定身份时保留失效条目，不冒认同名文件。快照同样在本机，请定期用胶囊备份到独立位置。

## 工作目标与数据迁移

浏览其他项目不改变快捷收集目标。要改变全局工作项目，使用项目设置中的「设为工作项目」或顶栏胶囊。

索引、关系、版本组、图谱位置、节点与快照存于当前配置的 `project-files` 文件夹。索引原子写入并保留 `.previous`，损坏时从有效副本恢复；双份损坏则停止写入。

胶囊已接入看板及快照；原件是否随包带走仍取决于所选项目目录和日期范围。旧 `.musyprojects` 关联备份不含看板与快照，完整迁移请用胶囊。

## 当前边界

当前实现人工确认关系、现有文件归组、显式快照和项目节点。专业格式全自动依赖解析、自动定时快照、云端协作和几何差异比较尚未实现。
