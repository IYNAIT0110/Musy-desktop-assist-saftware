# STArra v0.3.4 · 2026-10-31

本版加入顶部停泊的「星岛」，完善 mini 栏、星笺任务气泡与时间编辑，并包含全局搜索入口。现有项目、任务和资料库继续保留。

### 补充更新：刘海 MCP 彩带

本页安装版与免安装版已补充星岛 MCP 状态彩带，版本号仍为 v0.3.4。彩带沿刘海两侧和底部呈开口 U 形，贴屏幕的顶部没有彩带；处理时流动加快，等待确认时暂停，遵循减少动态效果设置。此次补充不改变数据格式。已下载早先 v0.3.4 的用户可重新下载安装，使用新的 SHA256SUMS.txt 校验。

## 小球变成星岛

- 收起功能栏后，将小球拖到当前屏幕顶部附近并松手，身体连续舒展为顶部中央的刘海；眼睛沿同一路径平滑移动，不用另一块面板替换小球。
- 星岛使用 Agent Robot Avatar 的机器人眼形，自动眨眼并响应处理、待确认、成功、失败等应用状态。自由小球保留原有表情。
- 左键展开/收起主功能栏；右键呼出 mini 栏，三个圆形按钮横向居中排列在刘海下方。自由小球的 mini 栏仍为弧形。
- 收起状态向下拖动返回自由小球；支持 Alt+↑ 停泊、Alt+↓ 返回、Enter/空格展开、Esc 收回及减少动态效果。
- 修复点击失效、开合横向晃动，移除小球悬停操作文字和停泊文字提示。透明区域可穿透。

## 一项任务，一个胶囊气泡

- 右键 mini 栏的「星笺」，显示当天任务，每项独立一个同宽、两端全圆的胶囊气泡；轻微间隔和悬浮阴影区分层次。
- 去掉「今日待办」标题、底部日期和关闭 X。点击任务可切换完成状态；点击刘海先隐藏气泡，不同时展开主导航。任务较多时可滚动。
- 星岛状态下气泡居中位于刘海下方，自由小球状态下继续跟随小球位置。

## 星笺与查找

- 时间编辑改用应用内小时、分钟下拉菜单，使用统一的 Glide Select 动画，可精确到分钟。
- 星笺页面异常时提供重新打开入口；渲染进程退出后可重建窗口，已保存任务保留。原始用户崩溃未在隔离副本中稳定复现，本版同时替换时间选择路径并补充异常恢复。
- 顶栏搜索按钮 / Ctrl+K 打开全局搜索，按已有本地索引查找资料，可选 AI 搜索需配置模型服务。
