# STArra v0.2.3 · 2026-10-28

本版将产品名称统一为 **STArra**，新增「胶囊」备份迁移和右键 mini 功能栏，并把完整使用文档内置到星砂。

## 胶囊：把工作带走

- 完整备份、最近修改、指定项目、日期范围，指定项目可叠加日期。
- 应用记录、当前资料库自有文件，以及选中的项目目录、外部引用原件和附加目录，打包为独立的 `.starrapack` 文件夹。
- 扫描清单、缺失确认、进度和取消、SHA-256 校验；恢复到新工作目录和独立配置，重建已打包路径后重启，当前数据保留。
- **范围只筛选原件，完整应用记录始终包含。** 默认可包含模型密钥，备份可能含私人内容，勿公开分享或当作客户交付包。

## mini 功能栏

右键小球打开「星笺、星轨、星镜」三个独立圆形按钮，分别承载今日待办、日程表、截图的方向。图标统一为星芒纸笺、环绕星轨与手持星镜，按钮直径 52px、沿用功能栏配色和材质，并更靠近小球。

支持依次展开、快速收回、反向衔接、屏幕边缘翻转、Esc 收回与键盘选择。**当前仅 UI 和按钮反馈，尚未接入待办、日程、截图。**

## 星砂与内置文档

- 新增「使用文档」文件夹：8 个主功能、3 个 mini 入口、设置与外观、工作流、产品故事，共 14 篇独立 Markdown，可逐篇导出。
- 「功能演示」提供普通文本、待办事项、AI 优化原稿。已有星砂内容保留，只补充一次；删除演示后不强行补回。
- 已有文档默认预览，待办预览可勾选完成；点击编辑区平滑收起列表和文件夹，支持 Markdown 格式、快捷键及 .md 导出。
- AI 优化需自行配置可信接口，结果先预览、可取消、另存或确认替换，模型可能产生费用，结果仍需核对。

## 品牌、外观与默认顺序

软件名称、安装显示与说明统一为 STArra。右下角为内置 Bodoni Moda 字体的 STArra 字标，与卡片右侧对齐；胶囊采用已确认的 A 版四芒星嵌口图标。

默认顺序：**星砂 → 织梦台 → 卷轴 → 百宝匣 → 传送门 → 秘籍 → 点睛笔 → 胶囊**。个人保存过的导航顺序仍保留。

新增静态磨砂颗粒材质，完善设置排版、恢复默认外观和页面切换。13 套配色、8 种材质，保留玻璃质感与可选背景模糊；真实桌面连续折射关闭。

## 下载与升级

- `starra-0.2.3-setup.exe`：Windows x64 安装版。
- `starra-0.2.3-portable.exe`：免安装启动版，使用当前 Windows 用户的应用数据目录，不代表所有用户数据随 exe 移动。
- `STArra-v0.2.3-docs.zip`：使用指南、工作流、产品故事、分功能 Markdown、示例与许可。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

请把安装包放在桌面或下载目录运行，**不要放在旧安装目录内**。保留旧数据目录和升级标识，兼容旧版收藏与资料。

升级前建议做一份独立备份。设计软件和授权需另行安装；点睛笔仍为占位，云同步、完整版本时间线与 Agent 自动接力未提供。
