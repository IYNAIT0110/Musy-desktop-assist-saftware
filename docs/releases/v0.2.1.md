# STArra v0.2.1 · 织梦台与统一资料索引

发布日期：2026-10-27。支持 Windows 10 / 11 x64，汇总 v0.2.0 之后的本地开发成果。

## 新增功能

- 第六个入口「织梦台」：项目创建、编辑、切换、归档，网站、母子卷轴和素材多对多关联。
- 顶栏项目胶囊：左键选择项目，右键或滑动开关切换自动关联。新资料关联开始操作时的项目，导入途中切换项目不会串数据；支持本次仅存公共库。
- 统一资料索引：检索网站、卷轴和当前百宝匣，支持类型、完整标签、多关键词和项目筛选，展示所属项目。
- 百宝匣批量添加、移除标签；全半角和大小写去重，批量失败不局部保存，详情可调整项目归属。
- 项目关系撤销、独立 `.musyprojects` 备份与「继续工作」。仅记录织梦台成功打开、复制，不监控其他软件。
- 回收区手动永久删除、移入满 30 天自动清理；软件关闭期间到期会在下次打开资料库时处理。
- 云白配色和液态玻璃材质，合计 13 套配色、7 种材质；支持底色浓度、高光强度和可选桌面背景模糊。
- 设置中的致谢与反馈页，统一轻弹标签、滑动下拉菜单和项目开关动画。

## 修复与改进

- 修复桌面模糊辅助层反复调整层级引起的轻微抖动与闪烁。
- 调整云白字标对比度、项目胶囊间距、同宽下拉菜单、开关对齐和横向工具栏。
- 索引分页和标签写入校验资料库身份，避免同 ID 跨库误操作，资料变化时更新索引。
- 保留玻璃通透材质和高光，关闭真实桌面折射、边缘扭曲及放大透镜；旧偏好不能重新启用。
- 更新使用指南、数据迁移、外观、回收区、项目和标签索引文档。

## 下载与升级

- `musy-desktop-assist-0.2.1-setup.exe`：安装版。
- `musy-desktop-assist-0.2.1-portable.exe`：免安装启动版。
- `Musy-v0.2.1-docs.zip`：离线用户文档。
- `SHA256SUMS.txt`：SHA-256 校验值。

程序尚未签名。升级前分别备份收藏/卷轴、百宝匣、原素材和项目关系，退出旧版再安装。升级保留用户资料，示例不覆盖已存在的库。便携版同样使用当前 Windows 账户数据目录。

`.musyprojects` 不含源素材，`.musybox` 不含外部原件或剪贴板原图。回收区永久清理会删除软件保存的剪贴板原图和对应库内记录，外部引用原件保留。

## 默认数据与范围

保留 64 个公开网站、3 条原创卷轴及示意插画、234 条离线快捷键资料。项目、素材库和 AI 配置初始为空，没有个人项目、实际提示词效果图、素材索引或密钥。

统一索引只覆盖当前连接的百宝匣、网站与卷轴，离线项目引用保留摘要。OCR、文件内容全文解析、完整文件版本管理、Agent、云同步和点睛笔仍未开放。玻璃不产生真实桌面连续折射。

## 源码与发布

公开 v0.2.0 源码和历史下载保留，后续源码私有开发。公开 v0.2.1 提供成品和用户文档；自动生成的 Source code 压缩包对应公开仓库文档树，不是新版完整源码。
