# STArra v0.3.5

## 星图

- 在主导航打开星图，按项目查看文件、关联资料、待核对项、最近工作和阶段存档。右侧最近待办汇总全局任务。
- 近一年文件热力图可切换日历与按周视图。点击日期或周柱查看对应文件，统计依据是文件索引中的最后修改日期。

## 织梦台

- 进入织梦台先看到项目卡片墙。封面优先使用自定义图片，否则使用近期带预览的项目文件。右键编辑项目名称、简介与封面，或将外部图片拖到卡片上更换封面。
- 文件看板可切换卡片、列表、时间和关系视图。时间视图按日期从新到旧，同一天的文件横排。关系图优化了大量节点时的拖动表现。
- 类型筛选包含链接和提示词。连线可通过 Shift 点选两个节点建立，双击连线解除。

## 星钉与 MCP

- 右键小球或星岛打开星钉。带时间、未排期、逾期待办集中显示。单击任务置顶或取消置顶，按住任务直到进度结束即可完成。完成箱保留记录。
- Agent 可呼出或关闭星钉、置顶待办、打开和刷新星图、读取文件修改日历与周统计、切换项目文件看板、扫描项目索引、设置索引文件为项目封面及管理文件连线。
- MCP 写操作沿用应用内确认。秘籍入口已下架。

## Windows 下载

- `starra-0.3.5-setup.exe` 提供常规安装。
- `starra-0.3.5-portable.exe` 提供免安装启动。数据仍保存在当前 Windows 用户目录。
- `STArra-v0.3.5-docs.zip` 包含使用说明与示例。
- `SHA256SUMS.txt` 用于校验上述文件。
