# STArra v0.2.0 · 收集、预览与复用

面向 Windows 10 / 11 x64。此次汇总此前在本地完成的功能与修复，并整理默认内容、使用指南及发布验证。

## 新功能

- 五个入口命名为传送门、卷轴、秘籍、点睛笔、百宝匣，配套简约线条图标；点睛笔仍是规划入口。
- 小球识别剪贴板完整网址并显示收藏邀请，支持关闭；自定义网站分组可长按拖动排序。
- 百宝匣 P0：引用原件、文件/文件夹导入、顶层目录自动分组、元数据与标签、筛选排序、缺失重新定位、回收恢复、索引与封面备份。
- 百宝匣 P1 的 BB-11 / BB-16：剪贴板与小球拖放收集、空格轻预览、滚轮缩放、两图并排、置顶参考、拖出真实文件。
- 读取常见图片和多种设计文件保存的缩略图，失败时尝试系统组件或手动封面；支持范围见格式文档。
- 卷轴母子卡牌堆，可拖动和箭头切换，详情图片平滑切换；支持 AI 辅助文档识别导入。
- 12 套配色、6 种表面质感、强度调节，三语文案与主要原生对话框补齐。
- Gooey Nav 导航动画、按钮水波与悬停反馈、方向感应卡片反馈、操作状态反馈。

## 修复与细节

- 分组过多时不再挤掉收藏按钮，统一面板、详情和菜单间距。
- 网站图标增加可靠回退和内置字标，包括 SANAA。
- 修复复制和删除按钮事件，删除确认在点击其他位置或切换版本时取消。
- 图片卡片缩略图等比铺满；圆形选择框，悬停/选择/焦点共用单层边框。
- 预览改为无系统标题栏，支持图片滚轮缩放。
- 小球与二级胶囊共用纵向画布，避免展开时纵向重定位；小球位置和底色保持一致。

## 默认内容与隐私

- 保留全部 **64 个公开网站**。
- 新库仅初始化 **3 条原创卷轴示例**：林间亭清晨、夜景子版本、社区阅读室；封面为示意插画。
- 不含开发者个人提示词、生成效果图、项目、素材索引、API Key 或缓存；百宝匣初始为空。已有内容不被示例覆盖。
- 秘籍的 234 条离线快捷键资料继续提供。

## 下载与升级

选择 `musy-desktop-assist-0.2.0-setup.exe` 或 `musy-desktop-assist-0.2.0-portable.exe`。应用未签名，请核对本页校验文件。文档包为 `Musy-v0.2.0-docs.zip`。

升级前请分别备份收藏/卷轴与百宝匣。`musy-data.json` 不含百宝匣；`.musybox` 不含原件，需另行复制引用文件和 `clipboard/` 图片。免安装版同样使用当前 Windows 账户数据目录。

## 验证与边界

发布工作流执行类型检查、单元测试、Windows 双版本构建、包内容审计、干净数据目录安装启动验证。CI 成功和产物详情见本标签关联的 Actions 运行。

缩略图受文件保存内容及系统组件影响，不保证所有专业格式版本均可预览。点睛笔、浏览器扩展、全局快捷键、智能文件夹、AI 相似搜索和完整原件打包仍在规划。
