# STArra v0.3.3 · 2026-10-29

本版为织梦台加入项目文件看板，把目录里的模型、图纸、图片和文档放在同一个工作视野中，并明确版本、时间与人工确认的文件关系。

## 文件看板

- 在项目文件夹内确认扫描，保留原文件位置，支持取消和进度；跳过符号链接、临时文件、开发目录和备份包，每项目最多 12,000 条。
- 文件、时间、关系三个视图，共享类型、状态、日期筛选；卡片/列表和修改时间、名称、大小排序。
- 图片和支持的设计格式显示缩略图，无可用预览时显示格式图标。选择两个文件可并排参考。
- 相同扩展名可人工归为版本组，展开查看、拆出或撤销；当前工作版本与最新修改、确认稿、交付稿分别标记。

## 圆点关系图与缩略图选择

- 以圆点、细线和名称表示文件关系，支持直接关联、两层、全项目、平移、缩放和拖动节点；单次显示最多 180 个文件。
- 导出/生成、引用、设计参考和分支关系由用户确认，支持记录来源快照。版本组以虚线相连，不假定版本先后。
- 建立关系的目标文件列表显示缩略图、文件名和路径；选中后保留预览，支持搜索和键盘选择。无法生成预览时显示扩展名。
- 刷新发现上游状态变化后提醒核对，保留人工判断，不自动修改下游。

## 内容快照与迁移

- 主动保存真实内容快照或命名项目节点，记录 SHA-256、检测保存过程中变化、支持取消。
- 默认快照总额度 5 GB，可调 1–100 GB；单文件最多 2 GB，每次最多 60 个文件。
- 历史预览、并排参考、校验后恢复为副本，拒绝覆盖已有文件。被关系/项目节点引用的快照受保护。
- 索引原子保存与损坏副本恢复；胶囊包含看板索引、版本组、关系和快照，恢复时重建已打包路径。
- 浏览项目与全局快捷收集目标分离，浏览另一个项目不会改变正在收集到的项目。

## 下载与升级

- `starra-0.3.3-setup.exe`：Windows 10 / 11 x64 安装版。
- `starra-0.3.3-portable.exe`：免安装启动版，仍使用当前 Windows 用户的数据目录。
- `STArra-v0.3.3-docs.zip`：使用指南、织梦台设计调研、开发交付说明、工作流、示例与第三方许可。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

建议升级前先创建胶囊备份。安装包请放在下载目录或桌面运行，不要放在旧安装目录内。已有用户数据、应用标识和数据目录保留；已有星砂文档不强行覆盖用户修改，新说明可在随包文档和 GitHub 查看。

扫描和归组不修改原件。当前需要手动刷新和主动保存快照，未保存的覆盖历史无法补回；多文件项目节点不是设计软件的原子保存。自动专业依赖解析、定时快照、云协作及几何差异比较尚未实现。旧 `.musyprojects` 关联备份不含看板和快照，完整迁移请使用胶囊。
