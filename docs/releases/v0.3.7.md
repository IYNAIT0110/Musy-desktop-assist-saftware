# STArra v0.3.7 · 星流工作助手

## 星流

- 左右贴边侧栏新增「快速问星流」。点击动态小球展开输入框，按 `Ctrl+Enter` 提交，按 `Esc` 收起。侧栏展开或收起时，入口跟随栏宽平滑变化。
- 星流对话支持复制、编辑后创建分支、流式文字和可折叠的工具步骤。标题栏可选择成果保存位置。生成文件和本地素材可保存到选定项目目录，重名时自动加编号。
- 星流可以搜索并读取卷轴里的母提示词和子提示词。只读模式允许查询资料和联网搜索，同时停用创建、编辑和文件生成工具。
- 联网参考图优先预览原网页提供的图片，并显示在对应引用下方。原网页预览不足时，可用 Wikimedia Commons 或 Openverse 补充。具体结果取决于网站是否提供可访问的预览。
- 官方 OpenAI 和 DeepSeek 模型配置可用于网页搜索。其他兼容接口可另外配置 Tavily。图片搜索的图库补充功能无需另配密钥。
- Agent 运行层增加模型与搜索超时控制，并在上下文过长时优先移除完整的旧轮次。

## 界面

- 全局统一字号层级，内置 Inter 和思源黑体；星流长回复使用更易读的正文尺寸和行距，支持鼠标选中文字。
- 星流和功能面板底板采用比侧栏更实的半透明背景。星流连同侧栏展开和收起时同步移动。

## 安装与更新

支持 Windows 10 / 11 x64。安装版和便携版随发布附上，也可下载使用文档和 SHA-256 校验文件。升级前可在「胶囊」中备份资料，安装包建议从下载目录运行。
