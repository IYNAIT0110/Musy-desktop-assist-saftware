# STArra v0.3.1 · 2026-10-28

本版新增可用的星笺任务时间线、中键呼出的 STArra 星灵，以及外部 Agent MCP 接入。卷轴支持由外部 Agent 保存图片、提示词与生成参数；涉及修改的 MCP 操作需要用户确认。

## 星笺与星砂

- 星笺按任务节点展示日程，提供周日期选择、未安排任务和当前时间提示；时间尺支持点击创建任务及滚轮浏览。
- 任务按持续时间布局，可调整时间段、完成状态，并与星砂中的关联待办同步。
- AI 提取的任务汇入对应分类的「AI星流」，按时间整理并去重；模型提供识别结果，程序负责关联、保存和同步。
- 星砂选择便签时仅收起文件夹栏，保留列表；点击正文进入编辑，点击空白区域回到预览，增加书写空间。

## STArra 星灵

- 中键点击小球打开对话窗口，沿用用户配置的模型。
- 模型通过工具按需查询任务、读取与修改便签、搜索本地资料或联网检索，支持多步工作。
- 可生成 Word、Excel、PDF、Markdown、TXT、CSV 和 JSON 文件，提供真实文件与打开、另存入口。
- 展示执行步骤，已完成的结果可在中断后保留并继续处理；新建任务支持撤销。
- 对话侧边尺按用户消息定位。联网搜索需单独配置 Tavily。

## 外部 Agent 与 MCP

- 在「设置 → 外部 Agent」开启连接，复制 MCP 配置给本机外部 Agent；需安装 Node.js，STArra 保持运行。
- 操作目录覆盖便签、卷轴、收藏、项目、素材、任务、外观与语言设置、备份等业务入口；可通过 list_operations 查询。
- 只读查询直接执行；新建、修改、删除及有副作用的操作会显示本次清单。批量声明可合并为一次确认；拒绝或关闭窗口不执行。
- 确认后重新检查权限及资料版本。客户端断开会取消待确认请求；批量执行中失败会返回已完成部分，不假定整体回滚。
- 文件目录由用户授权；支持文件读写、成果路径登记、项目关联、状态刷新、冲突检查及覆盖恢复副本。
- 卷轴的 save_prompt 工具会复制原图、生成预览，保存提示词、参数、标签及项目关联。托管原图进入胶囊备份，恢复时修正路径。
- 接入默认关闭；不提供密钥读取、任意代码执行或绕过确认的入口。外部 Agent 自身直接进行的系统文件操作不受 STArra 的确认窗口控制。

## 说明与限制

- 初始内容为 64 个网站、3 条原创卷轴示例、16 篇使用文档和 3 篇星砂演示；升级不覆盖用户修改或补回已删除的内置文档。
- AI 功能需自行配置可信接口，可能产生服务费用；星灵模型接口需支持工具调用。已验证本地模拟模型流程，不代表每家模型服务均兼容。
- 点睛笔独立页面、星轨和星镜仍有规划内容；云同步、全局选中文字润色及通用电脑控制未在本版提供。
- 胶囊仍包含完整应用记录，可能包含其他项目内容和模型密钥，不应当作脱敏交付包公开分享。外部接入授权、连接密钥、操作记录及成果索引暂不随胶囊迁移。

## 下载与升级

修复旧打包工具在全新 Windows 用户环境下的安装器兼容崩溃，保留旧安装位置及自定义安装目录。

- `starra-0.3.1-setup.exe`：Windows 10 / 11 x64 安装版。
- `starra-0.3.1-portable.exe`：免安装启动版，数据仍保存在当前 Windows 用户目录。
- `STArra-v0.3.1-docs.zip`：使用文档、示例及许可。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

升级保留原数据目录与应用标识。建议先使用胶囊备份，从下载目录或桌面运行安装包，不要放在旧安装目录内。

源码及版本标签同步私有开发仓库；公开下载仓库只发布软件、经过筛选的文档和许可，保留历史 v0.2.0 源码。公开 Release 的 Source code 压缩包不是新版完整应用源码。
