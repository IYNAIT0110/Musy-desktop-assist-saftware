# STArra v0.3.2 · 2026-10-29

本版完善外部 Agent 的小球反馈，新增流光光环与可调参数，并修复玻璃、悬浮栏、卷轴和素材界面问题。

## MCP 光环与气泡

- 接入、执行、等待确认、成功与失败都有对应反馈；状态不影响工具结果与修改确认流程。
- 原双星轨道保留，可在「设置 → 外观 → MCP 小球动画」切换到流光光环。
- 流光光环采用 React Bits Orb，位于球体外侧。大小 100%–115%、粗细 50%–250%，实时预览并保存，默认粗细 150%。
- 每个新工具调用触发约 1.3 秒的连贯动画：轻微放大约 6.5%并提亮、海浪波峰绕行一圈、恢复基础大小与亮度。同一调用恢复执行不重复触发，快速返回也能完成动画。
- 支持减少动态效果；保留透明背景与球体表情，修复光晕裁切、白色间隙和确认状态黑色方块。
- 气泡沿用收藏链接的圆角、尾巴及弹出动画。普通提示 8 秒、失败提示 12 秒、待确认提示 15 秒。
- 气泡与小球垂直居中、跟随拖动、屏幕边缘自动换边；移动不会重置停留时间。同一操作更新文字，不反复弹出。

## 界面与素材

- 提高玻璃工具栏与内容区可读性，统一卷轴列表和详情底板、底部操作区与品牌位置。
- 修复快速展开时列表被压缩、原生毛玻璃圆角、导航两侧背景板溢出及透明层显示问题。
- 优化百宝匣收集、导入反馈、整理及轻预览界面，保留已有资料与关联。
- 保留液态玻璃和可选系统模糊，真实桌面折射继续关闭。
