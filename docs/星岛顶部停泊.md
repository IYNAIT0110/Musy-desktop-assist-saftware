# 星岛 · 顶部停泊

适用版本：v0.3.4。

## 使用

1. 先收起功能栏，让 STArra 处于小球状态。
2. 拖到当前屏幕顶部约 24px 范围后松手，无需等待文字提示。
3. 小球移动到该屏幕工作区顶部中央，在约 440ms 内由圆形舒展成 112×30px 的刘海。沿用当前配色、材质和眼睛表情。
4. 点击星岛，从下方展开原功能导航；再次点击收起。右键 mini 栏、中键助手与拖入文件收集仍可使用，链接收藏提示显示在下方。
5. 在收起状态向下拖动，身体连续收圆，恢复自由小球。展开面板时先点击星岛收起，再拖动。

右键星岛可呼出 mini 栏，三个圆形按钮横向居中排列在刘海下方，按钮间距一致；自由小球仍使用弧形布局。右键其中的「星笺」可切换常驻今日待办气泡。星岛状态下每个任务独立显示为同宽胶囊气泡，居中停留在刘海下方。窗口宽 292px（窄屏自动适配），边缘为阴影预留空间，任务间距 8px。没有标题、日期或关闭 X；点击任务切换完成状态，点击刘海先隐藏气泡，不同时展开导航。任务较多时可滚动。

键盘：Tab 聚焦小球，Alt+↑ 停泊、Alt+↓ 返回小球；Enter/空格展开、Esc 收起。

## 动画与边界

### 机器人眼睛

星岛使用 [CX-ArtLab/agent-robot-avatar](https://github.com/CX-ArtLab/agent-robot-avatar) 的机器人眼形和动画，按 MIT 许可适配，版权与固定版本记录见第三方说明。保留 STArra 的身体、配色与材质，没有加入上游头部、天线和皮肤。

| 实际状态 | 星岛表情 |
| --- | --- |
| 闲置 | 自动眨眼、轻微张望；鼠标靠近时注视 |
| 模型处理 / 外部 Agent 工作 | waiting-wave 双眼轻微交错波浪 |
| 等待用户确认 | wary 警惕观察，保持到确认状态结束 |
| 完成 | success 笑眼与短暂轻动，随后恢复闲置 |
| 失败 | failure 垂眼，随后恢复闲置；并行批次中有失败时不以另一项成功掩盖 |
| 外部 Agent 接入 | affirm 轻点头 |

自动眨眼约隔 1.9–4.5 秒发生，闭合/睁开约 150–220ms。自由小球继续使用原 GrokBot 表情；变成星岛时，同两条眼睛路径逐渐变成机器人眼形并退出球面投影，拖回则反向恢复。状态中途改变从当前眼形继续，不重建或淡出换脸。减少动态效果关闭波浪、张望等持续动作，保留状态眼形。

这里只表现应用已确认的状态。内部模型请求结束不等于整项任务成功，不会仅凭网络返回就播放成功笑眼。

- 全程复用同一个身体、眼睛 SVG 和表情引擎，没有隐藏旧小球再替换新面板的步骤。身体尺寸/圆角变化，眼睛独立平移缩放，保留鼠标注视与眨眼。
- 只在主动拖到顶部并松手后停泊；普通经过顶部、打开功能页面不会触发吸附。
- 星岛停在当前显示器的工作区顶部，避免覆盖顶部任务栏；显示器断开或工作区变化后重新定位。
- 减少动态效果开启时取消空间移动，保留状态变化和可操作性。
- 透明区域不拦截后方窗口；导航、面板、气泡和身体仍可点击。
- 小球不再显示悬停操作说明，顶部吸附不再显示「松手，停泊星岛」。星岛开合时保持横向位置和宽度稳定。
- 当前停泊状态仅在本次运行中保留，重启仍从普通小球开始；尚未提供星岛独立尺寸设置和跨重启停泊位置记忆。

## 验证

除回归测试外，使用独立数据目录验证中间形态、身体/眼睛节点身份、顶部中央坐标、鼠标注视、导航/完整面板、快速收回再展开、链接气泡、拖动退出和减少动画。不同 DPI/负坐标显示器的几何边界有单元测试；尚未替代多种真实显示器组合的人工验证。
