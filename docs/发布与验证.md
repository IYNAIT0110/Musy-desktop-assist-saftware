# 发布与验证

策略更新于 2026-10-26：公开 v0.2.0 保留；后续源码私有开发，日常修改不发布。私人工作流只构建并保留私人产物，推送标签不自动公开发布。详见[私有开发与公开下载](私有开发与公开下载.md)。

## 发布内容

- Windows x64 NSIS 安装版与免安装启动版。
- `SHA256SUMS.txt`：当前 Release 产物的 SHA-256。
- `Musy-v0.2.2-docs.zip`：README、使用指南、专题文档、卷轴示例与许可。
- 对应源代码提交、版本标签、中文发布说明。

## 本地检查

建议 Node.js 22 LTS：

```bash
npm ci
npm run typecheck
npm test
npm run build:win
```

单元测试覆盖资料库导入/恢复/路径、缩略图解析边界、剪贴板与拖放、预置数据、主题、三语、动画状态和导航。`tests/treasureElectron.smoke.cjs` 是隔离临时库的隐藏 Electron IPC 测试，不操作现有用户资料库。

`scripts/check-package.cjs` 检查打包后的 asar 中没有个人备份、素材库、环境文件、密钥配置或开发机路径，并确认示例、第三方许可、版本信息完整。

## Windows CI

`.github/workflows/release.yml` 在干净 Windows runner 上依次：安装锁定依赖、类型检查、单元测试、构建双版本、检查发布包、安装到临时目录并用独立数据目录启动，再确认渲染进程和默认内容。

安装启动测试只证明基础安装与首次启动，不代表所有硬件、Windows 策略、设计软件版本和缩略图组件都兼容。完整视觉效果和真实格式样本仍需人工验收。

v0.2.0 的公开发布工作流作为历史保留在该标签下。当前工作流仅在私有仓库运行并保存 CI 产物。未来公开发布需用户另行明确授权，只上传经过筛选的软件产物与用户文档，不同步源码和 Git 历史。

## 发布前核对

1. package.json、lockfile、标签与说明版本相同。
2. 所有功能文档更新，规划功能明确标注；文档本地链接有效。
3. 初始内容为网站与原创示例，AI Key、个人提示词/图片、百宝匣索引不入库。
4. 第三方许可完整，安装版/便携版和文档包校验值齐全。
5. CI 成功后核对 Release 的文件名、大小、标签与目标提交。

## v0.2.2 发布范围

源码与 v0.2.2 标签推送到已核实为私有的开发仓库。公开仓库仅同步批准的用户文档、开源许可、安装版、便携版和 SHA-256 校验文件，不上传应用源码或私人 CI 日志。便签与 AI 界面测试使用独立数据目录和本地模拟模型。

## 升级与回退

升级保留当前账户用户数据。升级前分别备份 `musy-data.json`、便签 `notes.json` 及快照、百宝匣整库与原件。回退前同样备份，旧版不一定理解新版字段。不要用清空用户数据来模拟正常升级。
