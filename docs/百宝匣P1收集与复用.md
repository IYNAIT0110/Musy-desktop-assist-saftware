## BB-11：剪贴板图片入库、拖到小球收集

### 从剪贴板导入

在百宝匣左侧点击「从剪贴板导入」，或在素材列表获得焦点时按 Ctrl+V。支持复制的本地文件、文件夹、绝对路径和截图图片；名称、标签、搜索输入框内继续按普通文字粘贴处理。

剪贴板中的图片保存为资料库 `clipboard/` 下的 PNG 原件，然后建立素材条目。相同 PNG 内容使用相同保存路径，重复导入不会重复新增。不会持续监听并保存每一次复制，也不会为每张图片单独弹出提醒。

### 拖到小球收集

1. 从资源管理器拖动文件或文件夹，经过 Musy 小球。
2. 小球出现接收高亮和「松手，交给我收好」提示。最小球形态只展开一小块接收区；移开后约一秒恢复。
3. 松手开始导入。一批完成后显示新增、已有、失败数量，可点「查看」进入百宝匣。
4. 未设置资料库时会给出「设置资料库」入口；选好后继续处理刚才拖入的内容。失败时可重试，关闭提示不会删除已成功导入的素材。

文件夹沿用一级归组规则：只使用选中导入的最外层文件夹名称作为分组，包含其下所有文件，不创建子目录分组。

支持本地文件，以及来源应用实际提供了图片文件数据的拖放。对于只提供远程图片网址的浏览器拖放，本轮不会自动下载；可先复制图片，再用剪贴板导入。图片数据一批最多 32 张，输入与保存后的 PNG 总量分别限制为 128 MB；超过范围时分批导入。

本地文件仍采用引用模式。虚拟图片和剪贴板图片的 PNG 原件保存在 `clipboard/`，需另行备份；现有 `.musybox` 不包含这些原件。

## BB-16：轻预览、并排参考、拖出真实文件

### 空格轻预览

- 单击素材卡片，使卡片获得焦点，再按空格打开独立的预览窗。
- 左右方向键或「上一项 / 下一项」在当前列表页内切换，最多 60 项。
- 「适应」恢复初始比例，＋/− 或鼠标滚轮可在 0.5–4 倍适应尺寸间缩放；滚轮向上放大、向下缩小，尽量保持鼠标所指位置。Shift+滚轮保留滚动查看。
- 预览窗去掉系统标题栏和最小化/最大化/关闭按钮，可按住内置顶栏空白处移动，仍可调整大小。默认置顶；「已置顶」可切换为普通窗口，内置「关闭」退出预览。
- Esc 关闭窗口；预览区域获得焦点时空格也可关闭。按钮获得焦点时空格保留按钮的标准操作。
- 右击卡片继续进入资料编辑；双击卡片继续使用系统默认应用打开原件。

普通图片使用大尺寸图片预览；设计文件显示保存时的内置预览或用户封面，不执行模型、GH 定义或 PPT。无可读预览时显示格式占位和外部打开入口。

### 图片并排参考

1. 用 Ctrl 单击或复选框选中 2–4 张图片。
2. 点击选择栏「并排参考」。
3. 图片显示在同一个独立浮窗，2 张并列，3–4 张为两列网格。可置顶后回到设计软件工作。

比较窗与原资料库保持关联，主面板切换到另一个库不会把已打开的参考图错误地映射过去。每张图可以单独拖出；底部「拖出这些图片」可一起拖出。

### 拖出复用

- 从素材卡片按住左键拖动，可拖出真实原文件。拖动已选卡片会带上当前选择的素材，最多 60 项；拖动未选卡片只拖出该项。
- 在轻预览里拖动图片，或按住底部「拖出原文件 / 拖出这些图片」按钮拖动，也会传递真实文件。
- 拖动前逐项检查原件。任何一项缺失或仍在回收区，会拦截这次拖出并给出反馈，避免把占位图当作文件发送。
- 拖出期间小球收集暂时忽略百宝匣自身的拖放，避免重复收集。
- Windows 原生拖出沿用当前 Electron 的复制/链接能力，不请求移动操作，不由 Musy 删除源文件。接收软件实际执行的动作取决于它支持的文件类型与拖放方式。

资源管理器可作为复制/链接接收目标；SU、Rhino 等应用能否直接接受某种文件，要分别在对应版本里确认。拖出模型本体不等于自动打包外部贴图和参照文件。

## 验证与人工检查边界

- 主进程与前端 TypeScript 检查通过。
- 22 项数据测试通过，包含真实路径拖出解析、缺失/回收拦截、虚拟图片与本地 URL 拖入、预览会话隔离、比较数量与类型校验，以及既有导入、缩略图和备份回归。
- 隐藏 Electron 测试使用独立临时资料库，验证 preload/IPC、图片落盘、去重、缩略图和拖出参数；原生桌面拖放由测试替身拦截，不向用户桌面发起拖放。
- 未自动操作正式界面。小球接收区、键盘焦点、窗口置顶和缩放的视觉效果，以及资源管理器、SU、Rhino 的真实接收效果留给用户手动检查。

建议手动分别试用：复制一张截图；拖入一个本地文件夹到小球；空格预览一项素材；选中两张图片并排参考；拖出一张图片到资源管理器；再在已安装的 SU/Rhino 中测试其支持的模型文件。
