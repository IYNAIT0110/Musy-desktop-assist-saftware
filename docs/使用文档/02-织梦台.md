# 织梦台 · 项目关联

## v0.3.3：文件看板

项目内新增「文件看板 / 关联资料」。选择目录并确认扫描后，支持类型/日期筛选、卡片/列表、版本归组、时间视图和圆点关系图。勾选圆形选择框或按住 Ctrl 多选，相同扩展名可归组；卡片版本数展开，详情可以指定当前工作版本。

建立关系时可通过缩略图、文件名与路径选择目标，选中后保留预览。关系由用户确认，可标注来源、引用、设计参考与分支。来源变化后提醒核对，不凭同名自动建立依赖。选择文件保存真实快照或项目节点，默认额度 5 GB、可调 1–100 GB，单文件最多 2 GB、每次最多 60 个。详情可预览、并排参考、恢复为副本，不覆盖当前文件。

浏览项目不再自动改变快捷收集目标；通过「设为工作项目」或顶栏胶囊明确切换。迁移看板与快照请用胶囊，旧关联备份不含这些数据。当前需要手动刷新和保存快照，不能补回未保存的旧内容，也没有专业文件全自动依赖解析或几何差异比较。

织梦台将网站、卷轴和当前百宝匣资料关联为项目，帮助你回到正在进行的工作。

1. 打开织梦台，点击「新建项目」，填写名称、项目文件夹及说明。
2. 在顶部项目胶囊左键选择当前项目；右键或开关控制自动关联。
3. 开启后，通过小球快捷保存的新资料默认关联当前项目；保存界面可临时选择公共库。
4. 已有网站、卷轴、百宝匣素材可通过「关联项目」加入，同一份资料可以关联多个项目。
5. 在织梦台按类型、标签、关键词和项目筛选；「继续工作」记录近期打开、复制过的关联资料。

归档仅收起项目，不删除原件。关联不移动原文件，也不会自动复制完整项目目录。

旧的关联备份只包含项目、关系与检索摘要；要带走原件，请使用「胶囊」。跨软件自动追踪依赖、自动保存全部编辑历史与 Agent 接力属于后续方向。
