# 产品故事 · STArra 闪星

### 让创造，自有星图。

*Every idea has a place. Every creation has a story.*

## 品牌故事

每一个伟大的设计，都始于一个微小的闪光。

它可能是一张随手绘制的草图，一段突然出现的灵感，一次模型的调整，或是一场讨论中尚未成形的想法。

随着项目不断推进，这些微小的闪光逐渐变成图纸、模型、图像、文档与无数个设计版本。

然而，创作的过程并不总是连续的。

我们的灵感散落在不同的软件中，文件保存在不同的设备上，重要的设计决策遗留在聊天记录和会议里。一个设计版本为什么诞生、又为什么被取代，往往随着时间慢慢消失。

如今，人工智能带来了更多创作的可能。不同的 Agent 可以帮助我们绘图、建模、分析和生成方案，但它们之间依然存在一道道看不见的边界。

工具越来越强大，创作却可能变得更加碎片化。

我们开始思考：

**如果所有的创作，都可以被连接起来呢？**

如果每一份文件都能找到自己的位置，每一次修改都能追溯它的原因，每一个智能体都能理解项目的上下文，并在前一个智能体停止的地方继续工作。

如果更换设备、更换工具，甚至更换创作者，都不意味着重新开始。

这就是 STArra 诞生的初衷。

我们把创作过程想象成一片不断生长的星空。

**每一个想法，都是一颗星。**

文件、版本、决策和创作工具之间的关系，如同星星之间的连线。随着项目发展，它们逐渐形成属于自己的星座。

STArra 让这些关系变得清晰、可追溯、可延续。

它不试图代替设计师，也不要求所有创作都发生在同一款软件中。

它希望成为连接不同工具、不同设备、不同智能体与不同创作者的工作空间，让创造力自由流动，而不再被割裂的信息和重复劳动束缚。

**因为真正有价值的，不只是最终的作品，还有让作品得以诞生的整个过程。**

STArra · 闪星

**让创造，自有星图。**

## 核心主张

**连接创作过程中分散的想法、文件、版本、决策、工具与人，让每一步都有位置、有来由，也能被延续。**

> 上述品牌故事描绘长期愿景。v0.2.3 已提供胶囊的本地备份、复制与恢复；云同步、完整版本追踪和多 Agent 连续协作尚未实现。

## 功能命名与故事角色

| 名称 | 在故事中的角色 | 产品含义 | v0.2.2 状态 |
| --- | --- | --- | --- |
| 传送门 | 通往灵感世界的入口 | 收藏、分组、搜索并打开网站 | 已提供 |
| 卷轴 | 写下想法与变化的纸卷 | 保存提示词、预览图及版本关系 | 已提供 |
| 秘籍 | 随手可查的技能手册 | SketchUp、Rhino、AutoCAD 快捷键参考 | 已提供 |
| 点睛笔 | 给表达添上最后一笔 | 独立文字润色入口 | **规划中；当前仅有占位说明** |
| 百宝匣 | 收好创作材料的宝箱 | 收集、分类、预览与复用本地素材 | 已提供 |
| 星砂 | 让念头先落地的纸片 | 快速记录、待办、分类及整理 | 已提供 |
| 织梦台 | 把零散星光织成项目的工作台 | 项目关联、统一索引与继续工作 | 已提供 |

这些名字共同构成一段设计旅程：从「传送门」发现灵感，在「卷轴」中试验想法，用「秘籍」查找方法，把材料放入「百宝匣」，随时写进「星砂」，最后在「织梦台」汇聚成项目。「点睛笔」是未来为文字表达补上的一环。

「胶囊」把可携带的工作收好，当前已支持 .starrapack 文件夹备份与路径重建。mini 栏「星笺、星轨、星镜」承载未来日常工具，目前只完成 UI。

## 品牌定位

- **服务对象**：需要频繁收集参考、管理提示词与本地素材、推进多个项目的设计师及创作者。
- **产品角色**：本地优先、常驻桌面的创作伙伴与轻量工作台。
- **体验气质**：亲近、灵动、有秩序；像一颗随手可见的小星星，陪伴创作而不打断专注。
- **价值承诺**：让灵感有处可存、资料容易再找、项目能够接续。

## 口号

**主口号：让创造，自有星图。**

**英文表达：Every idea has a place. Every creation has a story.**

此前整理稿中的表达可作为延展文案：

- 把灵感收好，让创作发光。
- 从一颗闪星，走向完整作品。
- 灵感随手可得，创作自然连贯。

## 规划与表述边界

本文提到的「点睛笔」仍处于规划阶段，不应写成已上线功能。全局快捷键、浏览器扩展、智能文件夹、AI 相似检索及完整托管副本迁移等方向也尚在规划中。品牌叙事描述的是产品愿景，具体可用能力请以 [项目 README](../README.md) 和 [使用指南](使用指南.md) 为准。
