# 胶囊 · 备份与换机继续

胶囊把应用记录与选定原文件复制为一个可整体携带的 .starrapack 文件夹。它是个人备份与迁移入口，不是对客户的纯项目交付包。

## 完整备份

1. 打开胶囊，选择「完整备份」。
2. 确认项目文件夹、百宝匣引用原件、已配置数据路径；未连接资料库用「添加其他文件夹」加入。
3. 决定是否包含模型 API Key，默认会包含。备份可能含私人内容和密钥，请妥善保管。
4. 点击「扫描并预览」核对目录、文件数量、容量和缺失提示。缺失或无权限文件可先修复并重扫，或明确确认跳过。
5. 点击「选择位置并打包」，建议选择另一块磁盘。不要保存到备份源目录内部。

输出为 STArra-日期-编号.starrapack 文件夹，无需解压。必须整体复制，不能只复制清单或 state.json。

## 按范围导出

支持最近修改、指定项目、日期范围；指定项目还可叠加起止日期。日期以原文件最后修改时间为准，包含起止日，使用本机时间。

所有模式始终包含完整应用记录和当前资料库自有文件。范围只筛选原文件，未选原件的记录仍保留，换机后可能需要重新定位。仅扫描当前连接资料库和选定目录；链接与联接跳过并提示。

即使选择单个项目，仍可能包含其他应用记录与密钥，不应直接发给客户或公开上传。

## 在另一台电脑恢复

1. 安装 STArra，把整个 .starrapack 文件夹复制到新电脑。
2. 打开胶囊，点击「从备份恢复…」，选择备份文件夹。
3. 确认后选择新的工作目录位置。程序校验文件、复制原件并重建已打包目录的路径。
4. 恢复完成后自动重启，使用独立新配置继续。当前配置和原文件保留。

Rhino、CAD、Office 等第三方软件和授权需要另行安装。缺失或被排除的原件不会自动补齐。恢复不是云同步，不支持多人冲突合并。

文件复制后使用 SHA-256 校验；源文件在扫描后变化、磁盘不足或校验失败会停止，不会把未完成结果标成成功。
