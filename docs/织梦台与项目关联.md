# 织梦台与项目关联

本地开发版已新增项目文件看板、版本归组、圆点关系图和真实快照，优先阅读 [文件看板使用说明](织梦台文件看板.md)。浏览项目不再改变全局工作项目，完整迁移用胶囊。下文保留旧版关联模块的历史说明。

适用：v0.2.2 · Windows 10 / 11 x64 · 更新于 2026-10-27。

## 入口与使用顺序

1. 展开小球，在导航最右侧点击「织梦台」（小织机与星光图标）。沿用现有胶囊切换动画，二级导航加宽以容纳第六个入口。
2. 点击「新建项目」，输入项目名称，可选项目文件夹和说明。名称不能为空，也不能重复。
3. 点击「关联资料」，在传送门、卷轴、百宝匣之间切换，搜索已有资料并逐条关联；再次点击已关联条目可取消。
4. 在织梦台顶端搜索框检索本项目资料，支持名称、路径、标签、链接、卷轴正文和备注。条目可打开、复制或取消关联。

其他模块也可关联：传送门右键网站 → 关联项目；卷轴详情底部 → 关联项目；百宝匣选择一个或多个素材 → 关联项目。支持同一份资料关联多个项目，部分选中会显示「部分关联」。

## 当前项目与公共资料库

项目标签区隐藏横向滚动条，可用鼠标滚轮或触控板横向浏览，边缘渐隐提示还有未显示的项目。项目标签与同排工具按钮垂直居中对齐。

2026-10-27：公共资料库页现可统一检索网站、母子卷轴与当前连接的百宝匣；项目页复用同一索引，支持类型和标签筛选，并展示每份资料所属的项目。百宝匣支持批量增减标签和详情中的项目归属。详见[资产标签与统一索引](资产标签与统一索引.md)。

顶栏在功能导航和右侧系统按钮之间提供独立的项目胶囊，并与左右留出间距。左键项目名称打开菜单选择工作项目，右键切换快捷保存自动关联；右侧 Squish Switch 滑动开关也可直接点击或用键盘切换。滑块向右、强调色表示开启，向左、中性色表示关闭。切换采用速度驱动的拉伸回弹，开关轨道为 44×24px，在 34px 高的点击区域中垂直居中，外层胶囊保持 52px。减少动态效果时立即切换滑块位置。可通过键盘打开项目菜单，Shift+F10 调用右键切换。当前项目和开关在重启后保留。选择「公共资料库」可退出项目上下文，不能在没有工作项目时误开启自动关联。搜索框下方不再重复显示项目选择、开关和织梦台按钮。

已有项目升级后仍默认手动关联。选择项目后，可右键顶栏项目胶囊开启自动关联（织梦台内也保留开关），之后新收藏的网站、新建/另存的母子卷轴、确认导入的卷轴，以及百宝匣导入素材会自动关联当前项目，包括通过小球保存的网址、文件、文件夹和剪贴板图片。开关与当前项目在重启后保留；选择「公共资料库」时不建立项目关联。切换项目不会隐藏公共资料库，也不追溯归入已有资料。

传送门、卷轴和百宝匣的收集入口保留「本次仅存公共库」，成功保存一次后恢复普通模式。网址收藏气泡在自动关联开启时另有「公共库」按钮；向小球或百宝匣拖入时按住 Alt 也可只存公共库。项目关系不会移动或复制原件。

每次收集会固定开始时的项目；选择文件的对话框、导入队列运行期间切换项目，不会将后续文件归到新项目。目标项目在操作中归档时停止关联，原资料仍保存。再次导入已有素材时不重复创建条目，但可把既有素材关联到本次项目；回收区中的条目不自动恢复或关联。

关联只有在原资料保存成功后执行。原资料保存失败不创建空关系；项目关联失败也不撤销已保存的资料。网站和卷轴会显示可重试的关联提示，百宝匣在本批任务状态显示关联失败，可通过「关联项目」补齐。提示不是云端同步队列，关闭软件后未重试的提示不保留，资料和已完成的关联会保留。

## 继续工作

织梦台新增「项目资料 / 继续工作」切换。「继续工作」按最近实际使用时间排列仍关联在此项目中的资料，可继续打开、复制或搜索。它只记录用户从织梦台成功打开或复制的操作，不监控其他软件或整个系统；失败的打开、资料浏览和未确认的点击不计入。

近期操作记录随项目数据持久化和备份，全库最多保留最近 200 条操作；界面把同一份资料合并显示最新一次。归档不清空记录，取消资料关联后该资料不再出现在本项目的继续工作列表；重新关联后可再次显示。撤销项目整理操作不抹掉之后已发生的有效操作记录。

## 归档、取消与撤销

在项目页点击「删除项目夹」，确认后删除该项目、资料关联和此项目的近期操作记录。公共库的网站、卷轴、素材以及磁盘文件夹和原件保留，其他项目的关联不受影响。归档项目也可删除；删除当前项目后回到公共资料库并关闭自动关联。可用工具栏「撤销」恢复项目及关联，之后按需重新选择项目和开启自动关联。

- 编辑项目可修改名称、目录和说明。选择目录只保存引用，不扫描、移动或复制目录内容。
- 归档保留全部关联与源资料；在顶部横向工具栏的「已归档」中选中项目，再点「恢复项目」可解除归档。新建、状态筛选、公共资料库、项目切换及撤销/导出/恢复均在搜索框下方横向排列，项目较多时可横向滚动，内容区占满宽度。
- 取消关联只移除当前项目的一条关系，不删除网站、卷轴、百宝匣条目或磁盘原文件，也不影响其他项目。
- 「撤销上一步」支持本次运行内最近 20 次项目编辑、归档、关联和恢复。切换当前项目本身不占撤销记录；关闭软件后撤销记录不保留。

## 数据身份与不可用状态

网站和卷轴沿用现有条目 ID。百宝匣使用「资料库 ID + 素材 ID」，不按同名文件、路径或内容哈希合并。切换资料库后，其他资料库的条目显示未连接；项目打开与复制操作会再次核对资料库身份，防止打开同 ID 的其他文件。

条目删除、进入回收区或资料库未连接时保留关联和检索文字，标记源条目不可用。磁盘文件是否存在在实际打开时再次检查。重新连接原资料库或恢复原条目后，刷新织梦台即可重新读取。归档项目仍可浏览和移除关系，不允许新增关联。

## 备份与恢复

「导出关联备份」生成 `.musyprojects`，包含所有项目、当前项目、关联及检索文字（可能含路径、URL、卷轴文字和备注），不包含完整源资料库、预览图与素材原件。对外分享前应自行查看内容。

恢复会替换当前所有项目及关系，需先在界面确认。恢复前自动保留项目恢复点，也可以撤销本次恢复。无效、重复或孤立的关联记录会被拒绝，不覆盖有效项目状态。

项目单独保存在用户数据目录的 `projects.json`，通过临时文件、同步写入及原子替换落盘，并保留上一份有效副本。写入失败不会提前更新界面中的成功状态；主文件损坏时尝试有效副本，双份均损坏则停止常规写入，允许从有效备份显式恢复并保留损坏文件。

换电脑还需分别迁移收藏和卷轴的 `musy-data.json`、百宝匣索引与封面、素材原件。项目备份不代替这些备份。

## 与开发手册的对应

本轮实现 M1 中 PRJ-01 项目创建/编辑/归档/切换、PRJ-02 多对多关联与取消、基础 PRJ-03 项目资料搜索，以及必要的持久化、撤销和关系备份。既有 ID 不重新编号，项目关系不冒充文件内部依赖。

后续迭代补齐了自动收集关联和限定范围的近期打开/复制记录。本轮仍没有实现完整 M0/M1：最小手动任务、完整变更历史、卷轴图片磁盘化、专业文件版本身份、Agent、依赖分析和跨设备同步仍按开发计划后续推进。当前项目数据沿用本地单用户模式。

## 验证

新增自动测试覆盖项目重启持久化、归档保留关系、多项目/多库身份、去重与取消、撤销、并发写入、磁盘失败、备份验证和损坏数据恢复，以及旧项目迁移、固定收集目标、公共库覆盖、母子卷轴与批量收集、关联失败不丢原资料、近期操作上限。隐藏 Electron 测试验证真实导入途中切换/归档项目及重复素材复用。导航测试保留第六个入口及二级窗口宽度约束。界面外观由用户手动验收。
