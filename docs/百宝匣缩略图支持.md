# 百宝匣缩略图支持

> 2026-10-26 / v0.2.0 文档校准：本文为 v0.2.0 格式能力说明。缩略图为保存预览或系统提供的图像，不是完整模型/工程渲染。兼容性取决于文件版本及本机组件。 [使用指南](使用指南.md) · [发布说明](releases/v0.2.0.md)

本地更新日期：2026-10-25。保留手动封面优先，自动预览不会改写素材原件。

## 读取顺序

1. 有效的手动封面。
2. 文件中保存的内置预览。
3. Windows 已注册的缩略图组件。
4. GH/GHX 的兼容读取：尝试本机 Rhino/Grasshopper 安装目录中的 GH_IO.dll，仅读取文件字典，不执行定义和组件。
5. 无法读取时保留格式图标。

这里显示的是文件保存时的预览，不会自动打开建模软件重新渲染，也不提供旋转模型、运行 GH 定义或播放 PPT。

## 格式范围

| 软件/格式 | 已接入的路径 | 限制 |
| --- | --- | --- |
| Rhino `.3dm`、`.3dmbak` | 提取压缩/未压缩 DIB 预览，再尝试系统组件 | 支持常见 BITMAPINFOHEADER、8/24/32 位未压缩像素；文件需有可识别预览 |
| CAD `.dwg` | 读取预览索引中的 PNG 或 DIB，再尝试系统组件 | 兼容常见 AC10xx 头；不支持的版本和无预览文件依赖系统组件 |
| SketchUp `.skp`、`.skb` | 提取早期内置 PNG，或容器中的模型缩略图，再尝试系统组件 | 不把模型材质贴图当成预览 |
| Photoshop `.psd`、`.psb` | 提取 1036 号 JPEG 缩略图资源，再尝试系统组件 | 未保存此资源时依赖系统组件；不展开图层进行完整合成 |
| Grasshopper `.gh` | 解压字典并读取 Thumbnail 位图项，再尝试系统/GH_IO | 不把组件 IconOverride 图标当成文档预览；不计算定义 |
| Grasshopper `.ghx` | 提取 XML 中 Thumbnail 位图，再尝试系统/GH_IO | 图片清晰度取决于文件保存的预览尺寸 |
| PowerPoint `.pptx`、`.potx`、`.ppsx` | 提取容器 `docProps/thumbnail` 的 PNG/JPEG，再尝试系统组件 | 不生成全部幻灯片；缺失预览时依赖系统组件 |
| 旧 `.ppt`、其他 Office 文件 | `.docx/.xlsx` 尝试容器缩略图，其他情况尝试系统组件 | 对应组件需在当前电脑正常注册 |
| PDF、AI/EPS、DXF、视频等 | 尝试系统组件 | 不承诺每台电脑都有对应组件 |
| 常见图片 | 系统图片缩略图 | 保持现有等比铺满卡片、详情等比完整显示 |

旧库中的 PSD、GH、GHX、3DM 备份等条目在打开资料库时会更新类型分类，便于按图片、模型和文档筛选。分组、标签与原文件位置保持原样。

## 刷新与缓存

- 进入百宝匣即可自动读取，无需重新导入。
- 工具栏「刷新」会重新读取当前页缩略图；素材详情中「重试预览」会重试该素材。
- 手动封面始终优先。刷新不会覆盖已有手动封面。
- 正常缩略图保存在资料库 `cache/preview-v2-…png`。原件路径、大小或修改时间变化后使用新的缓存。
- 无预览结果在内存中保留约五分钟，避免反复读取；手动刷新和重试会绕过该等待。
- 损坏的自动缓存会重新生成。缓存写入失败时仍尝试显示当前读取结果。
- 安装新缩略图组件后，可直接点击刷新，不必重新导入素材。

## 性能边界

内置预览提取限制单次扫描与图片资源大小，避免把整个大型模型读入内存。Rhino/SU 前部扫描最多 16 MB；GH 直接读取的压缩文件最多 16 MB、解压结果最多 32 MB；PNG 预览最多约 1600 万像素，DIB 转换最多约 400 万像素。超出范围或不兼容时继续尝试系统组件。

Windows 系统缩略图读取放在专用隐藏渲染进程中，单次等待最多六秒，超时结束该进程，后续请求可重新创建。GH_IO 兼容读取也使用独立进程并限制等待时间。无需加载用户定义或打开对应软件窗口。

## 验证与来源

- `node --test tests/embeddedPreviews.test.cjs tests/systemThumbnail.test.cjs tests/treasureStore.test.cjs tests/treasureClipboard.test.cjs`：19 项通过，覆盖格式结构、损坏数据、读取/解压边界、超时恢复及现有导入存储回归。
- `tests/treasureElectron.smoke.cjs`：独立临时资料库和隐藏测试窗口验证真实 preload/IPC、系统图片缩略图、九种结构样例的预览解码、缓存、强制重试、原文件变化失效与手动封面优先。格式结构样例为人工构造，不代表所有软件版本的兼容性。
- 补充读取公开真实样例：McNeel `rhino3dm` 的 `tests/models/mesh.3dm`（1024×729）；Speckle `GrasshopperAsyncComponent` 的 `SampleGhFile.ghx`（150×100）；McNeel `compute.rhino3d` 的 `Hops_Example.gh`（150×100）及 `SimpleDelaunayMesh.gh`（300×200）。只作本地验证，未将这些模型纳入安装包。
- Rhino、DWG、SketchUp 格式提取参考并改编自 [cad-preview](https://github.com/cinderblock/cad-preview)，保留 [MIT 许可](../licenses/cad-preview-MIT.txt)，并随安装包分发。实现加入读取量、像素、解压量和结构校验限制。
- GH_IO.dll 不随软件分发，仅在本机已有安装时作为兼容路径。

正式界面的视觉验收及用户真实 PSD、DWG、SKP、PPT 文件的不同版本覆盖，仍由实际使用验证。相关功能纳入 v0.2.0 发布范围；实际产物见 Releases。
