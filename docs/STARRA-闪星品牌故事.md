# STARRA（闪星）品牌故事

> 品牌故事整理稿。依据“Starra / 闪星”的命名方向及项目仓库现有功能文档整理；原对话中的完整品牌故事正文未能从对话引用中读取，因此本文保留已可核实的名称与产品主张，并将叙事文案作为待确认稿。功能状态以公开仓库 README 所述 v0.2.2 为准。

## 一句话介绍

**STARRA（闪星）是陪伴设计师的桌面灵感工作台：把散落的网站、提示词、素材、笔记与项目线索，收进触手可及的一颗星里。**

## 品牌故事

每个设计项目，都从一瞬间的灵感开始。它可能是一张图、一段文字、一个网站，也可能是工作间隙突然冒出的想法。真正困难的，往往不是找到那束光，而是在繁忙的工作里留住它，并在需要时重新找到它。

STARRA 的中文名叫「闪星」。“闪”是灵感出现的瞬间；“星”是那些被收藏、被整理、彼此连结的创作线索。许多微小的闪光聚在一起，就能照亮一个项目从构想到完成的路。

因此，STARRA 希望成为设计师桌面上轻巧而可靠的伙伴。它在你需要时出现，帮你收藏、记录、整理、预览与复用；当你回到项目，线索还在那里，下一步也更清晰。

## 核心主张

**让每一瞬灵感，都能成为下一步创作的起点。**

产品围绕「收集 → 整理 → 预览 → 复用」展开：减少在网页、提示词、文件和项目之间反复寻找的时间，让创意保持连续。

## 品牌定位

- **服务对象**：需要频繁收集参考、管理提示词与本地素材、推进多个项目的设计师及创作者。
- **产品角色**：本地优先、常驻桌面的创作伙伴与轻量工作台。
- **体验气质**：亲近、灵动、有秩序；像一颗随手可见的小星星，陪伴创作而不打断专注。
- **价值承诺**：让灵感有处可存、资料容易再找、项目能够接续。

## 口号

**主口号：让每一瞬灵感，闪成下一步。**

可用于不同场景的延展表达：

- 把灵感收好，让创作发光。
- 从一颗闪星，走向完整作品。
- 灵感随手可得，创作自然连贯。

## 规划与表述边界

本文提到的「点睛笔」仍处于规划阶段，不应写成已上线功能。全局快捷键、浏览器扩展、智能文件夹、AI 相似检索及完整托管副本迁移等方向也尚在规划中。品牌叙事描述的是产品愿景，具体可用能力请以 [项目 README](../README.md) 和 [使用指南](使用指南.md) 为准。
