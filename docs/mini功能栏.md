# mini 功能栏（UI 预览）

右键小球，在小球左上方展开三个独立圆形按钮。靠近屏幕边缘时自动向另一侧翻转，避免裁剪。菜单独立显示，不改变小球与原功能栏的位置和尺寸。

三个入口为「星笺」（今日待办）、「星轨」（日程表）、「星镜」（截图）。当前仅提供按钮样式、悬停、点击选中反馈以及呼出和收回动画，**尚未接入实际功能**。点击不会读取待办或日历，也不会截屏。

再次右键小球、在 mini 栏内右键、按 Esc、点击其他窗口或移动小球可收回。支持 Tab 和方向键选择按钮，并尊重系统的减少动态效果设置。

每个按钮直径 52px、半径 26px，与功能栏胶囊端部一致；中心距小球约 76px，更贴近小球。去掉整块底板，按钮复用功能栏当前配色与材质。透明的按钮间空白区域不会挡住小球或下方窗口的鼠标操作。此功能随 v0.2.3 提供 UI 预览。


mini 栏仅保留三个独立圆形图标，名称与用途通过悬停提示显示，与主功能栏一致。
