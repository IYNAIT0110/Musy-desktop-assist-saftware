# 外观配色与质感

## 本地新增：磨砂颗粒（基于 v0.2.2，尚未发布）

设置 → 外观 → 表面质感 → 磨砂颗粒。作为第 8 种可选材质，保留当前配色，用固定的单色细颗粒形成磨砂表面。没有动态渐变、纹理移动或持续动画；可用「质感强度」调节，0% 关闭颗粒。覆盖面板、小球、导航胶囊、菜单和素材卡片，纹理位于文字和图片下方。偏好自动保存并同步到独立窗口，原有 7 种材质保留。

适用：v0.2.2 · Windows 10 / 11 x64 · 更新于 2026-10-27。

设置 → 外观：配色和材质分别选择，即时保存并同步独立预览窗。升级保留原有选择。

本地设置布局更新：左侧标题与导航共用背景，图标固定一列、名称右侧对齐；右侧内容独立滚动。外观页右下角固定「恢复默认外观」按钮，恢复石墨配色、经典哑光及默认质感参数后显示完成反馈；便签、收藏、素材和模型配置保留。

## 13 套配色

石墨、海蓝、森绿、暮紫、暖杏、玫瑰、靛蓝、青瓷、陶土、拿铁、冰川、橄榄，以及新增云白。云白使用柔白面板、深灰文字和蓝灰强调色，小球、气泡与右下角字标一并适配。

## 7 种材质

| 材质 | 效果 |
| --- | --- |
| 经典哑光 | 平整简洁 |
| 毛玻璃 | 半透明层次、柔和背景模糊与边缘亮度 |
| 液态玻璃 | 通透底色、圆润边缘高光和光泽；正文底色更实 |
| 牛皮纸 | 纸面颗粒、细碎纤维与暖色光影 |
| 毛茸茸 | 绒毛纹理与柔软明暗 |
| 亚麻织物 | 细密经纬纹理 |
| 温润陶瓷 | 釉面高光与内侧阴影 |

任意配色均可搭配材质。纹理位于表面底层，文字和图片保持清晰；纹理随软件内置，无需联网下载。

## 玻璃调节

- **质感强度**：0–100%，每步 5%，控制纹理和高光；经典哑光不需要此项。
- **玻璃底色浓度**：液态玻璃独立调节，默认 22%。降低后更通透，提高后更利于阅读。
- **模糊窗口下方的桌面背景**：可选 Windows 背景模糊，默认开启。切换材质、关闭选项、最小化或退出时辅助层隐藏或清理。

保留透明、高光和可选模糊，**没有真实桌面连续折射、边缘扭曲或放大透镜**。旧偏好不能重新启用这些效果。桌面模糊不采集、保存或上传屏幕图像；网页示例的折射不代表桌面窗口具备同样效果。

「恢复默认外观」恢复石墨、经典哑光和默认强度，仅影响外观。透明与模糊观感取决于系统合成、显卡驱动和桌面背景。v0.2.1 修复了模糊辅助层重复调整层级导致的抖动闪烁；也可关闭模糊并保留玻璃材质。

## 小球光环

外部 Agent 连接、执行、等待确认和返回结果时，小球会显示状态并弹出提示气泡。普通提示停留 8 秒，失败 12 秒，等待确认 15 秒；气泡与小球居中，拖动时跟随，靠边自动换边。拖动不延长停留时间。

在「设置 → 外观 → MCP 小球动画」选择流光光环或双星轨道。流光光环每次新调用会轻微放大并提亮，波峰转一圈后回落，约 1.3 秒；快速返回也会完成，等待确认恢复同一调用不重复播放。光圈大小和粗细可调并实时保存，系统减少动态效果时保持静态提示。反馈不改变权限、工具结果或修改确认要求。
