# 外观配色与质感

适用：v0.2.1 · Windows 10 / 11 x64 · 更新于 2026-10-27。

设置 → 外观：配色和材质分别选择，即时保存并同步独立预览窗。升级保留原有选择。

## 13 套配色

石墨、海蓝、森绿、暮紫、暖杏、玫瑰、靛蓝、青瓷、陶土、拿铁、冰川、橄榄，以及新增云白。云白使用柔白面板、深灰文字和蓝灰强调色，小球、气泡与右下角字标一并适配。

## 7 种材质

| 材质 | 效果 |
| --- | --- |
| 经典哑光 | 平整简洁 |
| 毛玻璃 | 半透明层次、柔和背景模糊与边缘亮度 |
| 液态玻璃 | 通透底色、圆润边缘高光和光泽；正文底色更实 |
| 牛皮纸 | 纸面颗粒、细碎纤维与暖色光影 |
| 毛茸茸 | 绒毛纹理与柔软明暗 |
| 亚麻织物 | 细密经纬纹理 |
| 温润陶瓷 | 釉面高光与内侧阴影 |

任意配色均可搭配材质。纹理位于表面底层，文字和图片保持清晰；纹理随软件内置，无需联网下载。

## 玻璃调节

- **质感强度**：0–100%，每步 5%，控制纹理和高光；经典哑光不需要此项。
- **玻璃底色浓度**：液态玻璃独立调节，默认 22%。降低后更通透，提高后更利于阅读。
- **模糊窗口下方的桌面背景**：可选 Windows 背景模糊，默认开启。切换材质、关闭选项、最小化或退出时辅助层隐藏或清理。

保留透明、高光和可选模糊，**没有真实桌面连续折射、边缘扭曲或放大透镜**。旧偏好不能重新启用这些效果。桌面模糊不采集、保存或上传屏幕图像；网页示例的折射不代表桌面窗口具备同样效果。

「恢复默认外观」恢复石墨、经典哑光和默认强度，仅影响外观。透明与模糊观感取决于系统合成、显卡驱动和桌面背景。v0.2.1 修复了模糊辅助层重复调整层级导致的抖动闪烁；也可关闭模糊并保留玻璃材质。
