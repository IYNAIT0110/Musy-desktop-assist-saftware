# 外观配色与质感

> 2026-10-26 / v0.2.0 文档校准：v0.2.0 已提供 12 套配色、6 种质感与强度调节。下列实现说明继续适用。 [使用指南](使用指南.md) · [发布说明](releases/v0.2.0.md)

入口：设置 → 外观。配色与质感独立选择，调整后即时生效并自动保存，已经打开的独立预览窗也会同步。

## 配色

共 12 套：石墨、海蓝、森绿、暮紫，以及新增的暖杏、玫瑰、靛蓝、青瓷、陶土、拿铁、冰川、橄榄。配色同时作用于面板、卡片、悬浮球、按钮和气泡。

升级后保留原先选择的配色，默认仍采用经典哑光，不自动更换外观。

## 表面质感

在外观页切换到「表面质感」，点击样卡选择：

| 材质 | 效果 |
| --- | --- |
| 经典哑光 | 平整、简洁的原有外观 |
| 毛玻璃 | 半透明层次、柔和透光、界面背景模糊与边缘亮度变化 |
| 牛皮纸 | 纸面颗粒、细碎纤维与暖色光影 |
| 毛茸茸 | 细密绒毛纹理、柔软的明暗和边缘光影 |
| 亚麻织物 | 细密经纬纹理和安静的布面效果 |
| 温润陶瓷 | 柔亮釉面、圆润高光和内侧阴影 |

纹理位于表面底层，素材图片、文字和输入内容保持清晰。可以将任一配色与任一材质搭配，例如拿铁 × 牛皮纸、玫瑰 × 毛茸茸、冰川 × 毛玻璃。

「质感强度」范围为 0–100%，每步 5%。毛玻璃的强度也会影响透明程度；其余材质主要调整纹理和光影。经典哑光没有纹理强度，选其他材质后滑块可用。

「恢复默认外观」恢复石墨配色、经典哑光和默认强度；只影响外观偏好。
