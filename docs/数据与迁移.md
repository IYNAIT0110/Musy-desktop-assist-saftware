# STArra 数据与迁移

首选[胶囊](备份与迁移.md)：应用记录、星砂、项目、偏好与选中的原文件统一生成 .starrapack 文件夹。范围只筛原件，可能含其他私人记录和密钥，请勿公开分享。

旧格式仍保留：musy-data.json 为网站/卷轴记录，.musybox 为百宝匣索引与封面，.musyprojects 为项目关系；不含全部原件，不能替代完整胶囊。

原用户数据目录与标识保持兼容。胶囊恢复会建立独立配置及新的工作目录，并重建已打包路径；旧配置和原件保留。应用关闭时复制原数据根目录也可作离线恢复点。

星砂文档内置说明会只补充一次，可编辑或删除。模型指令与密钥属于应用偏好，胶囊可选择是否包含模型密钥。网络请求只在相应操作发生时发给你配置的服务；图标抓取也可能访问外部来源。

当前没有云同步、多人冲突处理、自动 Agent 接力或第三方设计软件安装迁移。
