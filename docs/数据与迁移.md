# 数据、隐私与迁移

适用 v0.2.0，更新于 2026-10-26。

## 三类数据分开保存

| 数据 | 位置 | 迁移方式 |
| --- | --- | --- |
| 收藏、分组、卷轴与其预览图 | 当前账户 `%APPDATA%\musy-desktop-assist\` 下的 localStorage；可同步到指定目录 | 设置 → 数据路径，备份/恢复 `musy-data.json` |
| AI 配置、外观、语言与偏好 | 同一账户的本地浏览器存储 | 当前需重新设置；不包含在上述 JSON 中 |
| 百宝匣索引、封面、缓存、自有剪贴板图片 | 用户选择的 `Musy百宝匣` 目录 | 整库与原件一起复制，或索引备份配合原件另行迁移 |

AI Key 当前为未加密本地配置，请保护 Windows 账户和应用数据目录。复制整个应用数据目录可能包含密钥；分享数据前请检查内容。

## 收藏与卷轴备份

设置 → 数据路径，选择一个可写目录，生成 `musy-data.json`。文件包含 `version / savedAt / links / groups / prompts`；卷轴预览图随条目包含在其中。

恢复会替换当前收藏、分组与卷轴，界面会要求确认。恢复前先保留现有备份；它不是合并导入。此文件不包含百宝匣、API Key 或外观设置。

## 百宝匣资料库

资料库以独立 JSON 索引记录原件根目录和相对路径，保存原子快照与恢复点。普通导入为路径引用，源文件仍在原盘；应用缓存与自定义封面在库内。剪贴板位图写入库内 `clipboard/`，不是临时预览图。

管理资料库中的 `.musybox` 备份包含索引和封面，**不包含外部引用原件，也不包含 `clipboard/` 原图**。恢复会替换索引并先生成恢复点；这不能替代原文件备份。

推荐迁移步骤：

1. 结束导入任务，退出 Musy，复制整个资料库目录。
2. 复制库中所有外部引用文件；保留相对目录结构，勿漏掉大模型、贴图和文档。
3. 新电脑安装 Musy，选择复制后的资料库；路径变化时在管理页更换根目录，或逐项重新定位。
4. 检查几项原件能打开，再清理旧电脑的副本。

回收区只修改索引状态，不会删除引用原件。失联盘符或失效目录会显示原件缺失，勿通过清空库来解决路径问题。

## 网络行为

- 图标抓取可能访问原网站、图标服务及其重定向地址，并在本地缓存。
- AI 请求发往用户填写的接口，扩写/翻译发送当前正文，网站简介发送网址；文档识别发送提取文字，支持时附带少量参考图。
- 点击网站交给系统浏览器，外部服务按自己的规则处理访问。
- 剪贴板网址识别在本地进行；提醒可关闭。素材入库本身不会把本地文件上传到云端。

当前没有账号、云同步或自动更新服务。Core 离线功能无需 AI Key。

## 发布包清洁范围

v0.2.0 新用户得到 64 个公开网站、3 条原创示例卷轴及示意插画、秘籍离线资料；百宝匣和模型接口配置为空。用户备份、项目素材、生成效果图、索引、缓存与本地配置均不随发布包分发。

已有库升级不覆盖提示词；已删除示例不自动补回。免安装 exe 仍使用当前账户数据，单独拷贝 exe 不会迁走收藏。
