# 百宝匣 P0 使用与交付说明

> 2026-10-26 / v0.2.0 文档校准：v0.2.0 已交付 P0，并加入 P1 的 BB-11 与 BB-16。空格现为独立轻预览，右键卡片查看/编辑；目录导入仅按顶层目录建组。备份不包含原件，剪贴板自有原图也需另外迁移。 [使用指南](使用指南.md) · [发布说明](releases/v0.2.0.md)

日期：2026-10-25。范围：本地素材索引首版。状态：功能已实现；数据测试与 Electron 接口冒烟验证完成，视觉交互和跨电脑验收留待实际使用。

## 第一次使用

1. 点击顶部的「百宝匣」小宝箱，选择「选择或创建资料库」。
2. 选一个本地文件夹。首次会在其下创建 `Musy百宝匣` 子目录；再次选择已有资料库目录即可打开。
3. 点击「导入文件」「导入文件夹」「从剪贴板导入」，或者把文件/文件夹拖到素材列表。
4. 首版采用**引用模式**：只登记原文件的位置，既不移动原件，也不把大模型复制一遍。
5. 右击素材卡片打开「素材详情」，为模型选择封面，填写名称、分组、标签、备注、来源和授权信息。

建议先用一个项目的资料目录试用。不要移动资料库内部的 `catalog.json` 或 `covers`；用户原件可以继续留在现有模型、材质文件夹。

## 已实现的 P0 能力

| 计划任务 | 本次实现 |
| --- | --- |
| BB-01 独立存储 | 主进程管理版本化 JSON 索引，临时文件写入、刷新文件、原子替换；保留上一版有效快照。封面独立保存，不进入浏览器存储 |
| BB-02 文件引用 | 原资料根目录与相对路径分开记录；列表检测文件是否可访问；可更换整个根目录或重新定位单个文件 |
| BB-03 本地导入 | 多文件、文件夹递归导入和拖入；后台分批保存；取消、失败明细、重复路径跳过、重试；重启将进行中的旧任务标为中断 |
| BB-04 卡片与封面 | 图片、常见设计文件内置预览与系统缩略图；手动封面优先；用户封面独立保存，缺失原件仍可查看；支持缓存和强制重试，详见《百宝匣缩略图支持》 |
| BB-05 分类与字段 | 分组新建、改名、删除和排序；侧栏长按拖动排序，管理界面也可用上下按钮；多选归组；名称、标签、备注、来源、作者、授权备注 |
| BB-06 检索 | 顶部关键词查询名称、原文件名、标签、备注等；分组、类型、精确标签筛选；最近导入、最近使用、名称排序；保留筛选偏好；每页 60 项 |
| BB-07 打开复用 | 双击或 Enter 用默认应用打开原件；空格查看详情；打开所在位置、复制路径；重新定位后保留条目资料 |
| BB-08 回收与撤销 | 单选/多选移入回收区、撤销移除、在回收区恢复；不删除用户引用的原件 |
| BB-09 备份恢复 | `.musybox` 包含索引、分组、标签和自定义封面；恢复前显示数量和范围；先保存当前完整恢复点，再替换索引；损坏备份拒绝恢复 |

## 浏览与操作

- 「从剪贴板导入」支持资源管理器复制的文件/文件夹、多行绝对路径、`file://` 路径，以及截图或复制的图片。列表区域获得焦点时也可按 Ctrl+V；名称、标签、搜索等输入框内仍为普通文字粘贴。网页 URL 继续使用传送门收藏。
- 剪贴板中的本地文件沿用引用导入；图片保存为 PNG 到资料库的 `clipboard/`，再建立条目，相同图片重复导入按保存路径去重。此目录是图片原件，请保留；现有 `.musybox` 备份仍只包含索引与封面，**不包含这些剪贴板图片原件**，换电脑需一并复制该目录并按需重关联根目录。
- 单击卡片选择；Ctrl/Command 单击或勾选复选框进行多选。
- 双击或 Enter：通过系统默认应用打开原件。未安装对应设计软件时可继续管理索引、查看自定义封面。
- 右击素材卡片：打开「素材详情」查看与编辑。空格打开独立轻预览；选中 2–4 张图片可并排参考，卡片可拖出真实文件。详见 [P1 收集与复用说明](百宝匣P1收集与复用.md)。方向键移动卡片焦点，Esc 关闭详情或取消选择。
- 在详情中修改的是百宝匣显示名称，不会改原磁盘文件名。
- 标签用逗号分隔；工具栏的「筛选标签」按完整标签精确匹配，顶部搜索框按文字查询。
- 排序可选最近导入、最近使用、名称、文件日期和文件大小。文件日期按记录的原件最后修改时间从新到旧，文件大小从大到小；两项基于导入或重新定位时保存的文件信息。排序选择会保留。
- 分组删除后素材归入「未分组」，原件与封面不会删除。
- 文件夹导入（含拖入文件夹）会递归读取子目录，只按本次选择的最外层文件夹名称创建一个分组。例如选择「项目」导入，`项目/贴图/木纹.png` 和 `项目/模型.skp` 都归入「项目」，不创建「贴图」等子目录分组。同名分组复用，空文件夹不创建分组；名称超过 80 字时截取前 80 字。
- 更新前最近一次导入产生的子目录分组会在打开资料库时合并至该次导入的根目录分组，并移除合并后为空的子分组。旧版没有记录分组来源，仅处理该次任务中更新且仍与直接父目录同名的条目，保留其他手动分组。
- 相同路径不会重复新增条目。重新导入文件夹时，会给库中已有的「未分组」素材补充分组，保留已有分组与回收区状态。之前导入的素材可用此方式补齐归组；单独导入文件保持原有的未分组方式。这是路径去重，不是文件内容去重。
- 目录扫描不会跟随其中的符号链接，也不会把百宝匣自身的索引和缓存再次导入。

## 文件格式范围

- JPG/JPEG、PNG、WebP、BMP、GIF：登记、按需缩略图、放大适应窗口预览、外部打开。动画文件首版不承诺内置播放。
- SKP、3DM、DWG、PSD、GH/GHX、PPTX 等已接入文件内置预览与系统缩略图回退；其他文件继续作为引用管理，支持手动封面与外部打开。**不提供原生 3D 交互预览**。支持条件详见 [百宝匣缩略图支持](百宝匣缩略图支持.md)。
- PDF、视频等会尝试系统缩略图；音频、字体等可登记并外部打开，内部专用阅读器/播放器后续实现。
- 图片缩略图读取依赖 Windows 原生能力。过大或无法解码的图片会保留格式占位图，可指定自定义封面。
- 模型的外部贴图和参照文件不会被自动解析、复制或打包。原件的目录关系仍需由用户维护。

## 数据与备份边界

资料库目录：

```text
Musy百宝匣/
  catalog.json             素材、分组、根目录和导入任务
  catalog.json.previous    上一版有效索引
  covers/                  用户指定的封面
  cache/                   可重新生成的图片缩略图
  clipboard/               从剪贴板保存的图片原件（需另行备份）
  recovery/                恢复前的索引和封面备份包
```

资料库位置单独记在应用用户目录的 `treasure-settings.json`。重新安装软件不会主动清除用户选定的资料库。

在「管理资料库」中导出 `.musybox`：

| 内容 | 是否包含 |
| --- | --- |
| 素材名称、路径引用、标签、分组、备注、作者与来源 | 包含 |
| 自定义封面、回收区中的条目和封面 | 包含 |
| 引用的模型、贴图、视频等原始文件 | **不包含，需另外复制或备份** |
| 自动缩略图缓存 | 不包含，按需重建 |
| 传送门和卷轴数据 | 不包含，继续使用其原有 `musy-data.json` 备份 |

换电脑时，安装 STArra，建立/选择资料库，恢复 `.musybox`，再将原资料文件夹复制到新电脑。若位置不同，点「管理资料库 → 原资料位置 → 更换根目录」，保持原根目录下面的相对结构；单个文件搬家则在素材详情中选择「重新定位」。

恢复成功指索引和自有封面恢复，不代表外部原件也已迁移。文件不可访问时，卡片会显示缺失提示。

索引损坏时会尝试上一版有效快照，并保留损坏文件；两个索引都无法读取时不创建空库覆盖。恢复点在 `recovery` 目录，可再次通过「从备份恢复」选择。导出需要等待导入结束或取消，保证备份有明确的一致状态。

当前保护性上限：100,000 条索引、索引 64 MB、备份读取 256 MB；封面导出会提前检查估算体积。普通位图源文件超过 128 MB 时不自动生成缩略图；大型设计文件可尝试有界提取内置预览，具体见缩略图支持说明。以上是边界限制，不代表已验证同规模下的全部性能。

## 验证记录

1. TypeScript 主进程与前端类型检查通过。
2. `node --test tests/treasureStore.test.cjs`：10 组隔离临时目录测试通过，覆盖真实文件引用导入、根目录自动归组、子分组合并、同名分组复用、旧条目补齐归组、手动分组与回收区保留、路径去重、分类/标签搜索、重启、取消/重试、根目录迁移、单文件定位、封面备份恢复、损坏索引恢复、无效备份拒绝和写入失败后的恢复。
3. 其中 5,000 条测试验证的是元数据搜索和分页，不是 5,000 份真实模型、图像的整机性能压测。
4. 隐藏 Electron 冒烟测试验证 preload → IPC → 存储、Windows 原生 PNG 缩略图、详情读取、编辑及回收恢复。测试使用独立临时资料库，未读取用户素材。
5. 按用户既有要求，未自动操作正式软件界面做视觉验收。真实 SKP/3DM 打开、移动硬盘、大量真实图片、多 DPI 及干净 Windows 账户/另一台电脑的验收尚待完成。
6. `node --test tests/treasureClipboard.test.cjs`：4 组剪贴板数据测试通过，覆盖 Windows 多文件数据解析、中文与空格路径、路径文本与 file URL、损坏格式回退、图片保存与去重、重启读取和文件夹一级归组；结合存储测试共 14 项通过。系统剪贴板实际复制/截图的交互效果留待手动验收。

当前百宝匣新增界面文案以中文为主；基础导航继续保留现有语言切换。多语言覆盖、托管副本、原件迁移包、内容哈希去重和原生 3D 预览不在本轮交付范围。

## 手动验收建议

1. 导入一个含中文路径、SKP/3DM、PNG/JPG 和未知格式的小目录，确认数量和原件位置。
2. 给模型指定封面、分组和标签；搜索并打开一次，再重启检查数据。
3. 移除并恢复条目，确认原磁盘文件仍然存在。
4. 导出备份，换一个测试资料库恢复；核对封面、分类和数量。
5. 用文件副本测试更换根目录和单文件定位；确认缺失提示可消除。

上述过程建议使用资料副本。本轮仅本地开发和安装，不发布 GitHub 版本。
