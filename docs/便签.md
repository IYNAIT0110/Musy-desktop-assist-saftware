# 便签

适用版本：v0.2.2 · Windows 10 / 11 x64。

功能栏的便签图标（可拖动排序）打开记录面板，正文会自动聚焦。选择「普通文本」写随记，或选择「待办事项」添加可勾选的任务。待办输入框按回车添加下一项，支持中文输入法；模板切换保留已写内容。点击「新便签」先保存当前记录，再打开一张空白便签。

输入停止约 350 毫秒后自动保存，离开输入框、切换便签和收起面板也会尝试提交待保存内容。「已保存到本机」只在写盘成功后显示；失败时编辑内容保留，可重试。

界面采用三分区：左侧显示当前分类全部便签，右上为 Folder 分类区，右下为书写区。默认提供随手记、工作、灵感，可新建分类。编辑区底部的菜单可调整当前便签分类。Folder 使用 React Bits 的 flap 模式，尺寸为 0.82，悬停展开并预览最近三条便签；点击纸张继续编辑。点击文件夹时，内容以纸张飞入左侧列表的动画呈现，并默认打开该分类的新建普通文本便签，无论分类是否为空或此前使用何种模板。减少动态效果时使用短暂淡入。文件夹区域支持滚轮横向浏览，左侧列表与书写区独立滚动；顶端搜索框搜索当前分类的标题、正文和待办内容。

列表删除按钮需要再点一次确认，删除后可撤销最近一次删除。分类、文本和勾选状态保存在 `%APPDATA%\musy-desktop-assist\notes.json`，写入时保留 `.previous` 快照；损坏主文件可恢复上一次快照，双损坏会提示错误而不会初始化空库。保存不依赖联网或 AI。

右键文件夹可编辑名称、颜色与备注；保存后同步更新封面和分类菜单，不改变已有便签的归属。名称须非空且不重复。备注可在悬停提示中查看。Folder 上部保留完整展示空间，横向浏览区根据剩余内容显示两端渐隐，到达末端后对应渐隐自动消失；展开纸张继续使用顶层浮动展示。

现有 `musy-data.json`、`.musybox` 和 `.musyprojects` 备份不包含便签。迁移便签时请先退出 Musy，另行复制 `notes.json` 与 `notes.json.previous`。

Folder 来自 React Bits，许可见 [React Bits Folder MIT](../licenses/react-bits-Folder-LICENSE.txt)；保留原动画，适配 React 18 类型及空分类行为。

## AI 优化

编辑区底部新增「AI 优化」。左键使用设置中已有的模型接口、模型与 API Key 整理当前便签；右键或 Shift+F10 打开优化设置，可选择智能重点整理、自定义提示词、自定义 Skill。Skill 可直接粘贴，或导入不超过 60,000 字符的本地 SKILL.md / Markdown 文件。选择模式与内容后点击保存。

内置使用 [CoCo meeting-notes](https://github.com/coco-research/coco/tree/2e838244a0c6a2309e51752fa151b6e335f99b78/skills/meeting-notes)，保留 MIT 许可。默认“智能重点整理”提取重点、行动项、决定、截止时间和待确认事项，简单便签不强制套用完整会议纪要。每次请求由主程序读取电脑的系统日期、时间和时区，提供今天、明天、后天及本周/下周日历，将明确时间转为 YYYY-MM-DD 或 YYYY-MM-DD HH:mm。没有时分不补造，缺少年份时标注推定，“尽快”等不明确时间保留并标注待确认。Skill 只作为模型指令，不执行脚本、工具、项目目录读取或文档同步；自定义提示词和 Skill 设置继续保留。

点击优化仅发送当前便签和所选指令到配置的接口，可能产生服务费用。无需为便签单独配置一套模型；没有配置时可直接进入「模型设置」。请求可取消，最长等待 90 秒；网络失败、鉴权错误、输出截断均不会替换原文。

结果在编辑区内预览，突出标题、日期、待办和待确认信息；可展开查看原文及完整 Markdown。确认后可替换当前内容，或另存为普通文本新便签。替换后可一步撤销到替换前的内容。请求期间原便签改变会禁止覆盖；待办结果若未保留任务数量和完成状态，则只能另存为普通文本，不覆盖原清单。结果仍需用户核对，不代表模型已验证事实。

## 书写与浏览

左侧笔记列表显示标题、两行摘要和更新时间；悬停或键盘聚焦时显示删除操作。顶部拟物文件夹保持滚轮横向浏览、右键编辑及展开预览。点击「专注书写」将文件夹收成紧凑分类条，增加正文空间，点击「展开文件夹」恢复。分类条切换文件夹仍默认新建普通文本，已有内容从左侧列表打开。

选中普通文本后出现加粗和列表工具，直接插入 Markdown；未选中文字时收起。正文自动保存、待办完成状态及删除撤销继续有效。

优化偏好单独保存在本机，不包含在 notes.json 或现有导出包中。验证使用本机模拟接口验证请求、预览、取消、错误与保存流程，未使用真实用户密钥或消耗真实服务额度。
