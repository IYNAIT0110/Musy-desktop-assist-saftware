# SketchUp 快捷键白皮书

> 数据来源：SketchUp 官方帮助中心「默认键盘快捷键」（help.sketchup.com）。
> 适用于 Windows；macOS 下 `Ctrl` 对应 `⌘ Cmd`、`Alt` 对应 `⌥ Option`。

## 工具（官方默认）

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 选择 |
| `Shift + Space` | 套索选择 |
| `B` | 颜料桶（材质 / 纹理 / 环境） |
| `E` | 橡皮擦 |
| `L` | 直线 |
| `R` | 矩形 |
| `C` | 圆 |
| `A` | 两点圆弧 |
| `M` | 移动 |
| `P` | 推 / 拉 |
| `Q` | 旋转 |
| `S` | 缩放 |
| `F` | 偏移 |
| `T` | 卷尺 |
| `G` | 制作组件 |
| `I` | 图像穹顶（照片匹配） |
| `K` | 后边线（Back Edges） |
| `Shift + S` | 搜索 |

## 视图与导航

| 快捷键 | 功能 |
| --- | --- |
| `O` | 环绕观察（或按住中键拖动） |
| `H` | 平移（或 Shift + 中键拖动） |
| `Z` | 缩放（或滚动滚轮） |
| `Shift + Z` | 缩放范围（充满视野） |

## 编辑与系统（通用）

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + C` / `Ctrl + V` / `Ctrl + X` | 复制 / 粘贴 / 剪切 |
| `Ctrl + A` | 全选 |
| `Ctrl + S` | 保存 |
| `Ctrl + G` | 创建组件（组） |
| `Delete` | 删除 |
| `Esc` | 取消当前操作 |

## 高效技巧（组合键）

| 操作 | 效果 |
| --- | --- |
| 移动时按住 `Ctrl` | 复制而不是移动 |
| 复制后输入 `5x` | 复制 5 份（阵列） |
| 复制后输入 `/` | 等分间距复制 |
| 双击推拉 | 重复上一次推拉距离 |
| 三击选择 | 选中所有相连几何体 |
| 方向键 | 锁定红 / 绿 / 蓝轴推理（上 = 蓝轴） |
| `Shift` + 推理 | 锁定当前推理方向 |

## 使用技巧

- **自定义快捷键**：窗口 → 偏好设置 → 快捷键（Windows），可搜索命令、点「添加」绑定新键，并支持导出 `.dat` 分享。
- **中键是灵魂**：环绕 / 平移 / 缩放都集中在中键上，三键滚轮鼠标几乎必备。
- **建议首日绑定**：Hide（隐藏）、Make Group（建组）、Toggle X-Ray（X 光）、Purge Unused（清理未用）——官方默认没绑，但高频。
