# STArra · 闪星

**让创造，自有星图。**

## 产品定位

设计项目的上下文往往散落在文件夹、浏览器收藏、聊天记录和临时便签中。STArra 将这些资料组织到同一个桌面入口，同时保留原文件的位置与原软件的工作方式。

- **围绕项目组织工作。** 把目录文件、版本组、参考关系、提示词与素材放回对应项目，区分正在浏览的项目和当前收集目标。
- **保留可以核对的历史。** 主动保存真实文件快照，用关系图和时间视图理解文件来源、变化与用途。
- **让 AI 参与具体操作。** 可选模型助手与本地 MCP 接入，查询应用资料、整理任务、生成文件，并让修改操作经过确认。
- **保持轻量的桌面入口。** 左键展开功能栏、右键打开 mini 栏、中键呼出星灵；无需账号即可使用本地功能。

适合需要管理模型、图纸、图像、文档和参考资料的建筑、室内、景观及其他设计工作者。STArra 不替代专业设计软件，也不把人工确认的文件关系当成自动解析的专业依赖。

支持 **Windows 10 / 11 x64**。应用界面支持简体中文、英语与日语。

1. 从下载目录或桌面运行安装包，**不要把安装包放在旧安装目录内运行**。升级前建议先创建胶囊备份。

3. 在「文件看板」确认扫描范围，或先用「星砂」记录想法、「传送门」收藏参考网站。
4. 需要 AI 时再配置可信的模型接口；需要外部 Agent 时再开启 MCP 并授权目录。两者均为可选功能。

## 功能总览

| 模块 | 主要能力 |
| --- | --- |
| **星砂 · 笔记与待办** | 普通文本、待办清单、Markdown 编辑与导出、专注书写、可选 AI 整理；内置 16 篇使用文档与 3 篇演示 |
| **织梦台 · 项目工作空间** | 项目文件看板、时间视图、关系图、人工版本归组、真实内容快照、项目节点及跨模块资料关联 |
| **卷轴 · 提示词工作台** | 母子提示词、预览图、标签、复制、卡牌切换；可选 AI 扩写与翻译，支持外部 Agent 保存图片、提示词及生成参数 |
| **百宝匣 · 素材资料库** | 文件夹与剪贴板导入、原件引用、标签分组、支持格式的缩略图与轻预览、并排参考、拖出原件 |
| **传送门 · 网站收藏** | 收藏、分组与搜索参考网站，内置 64 个公开网址 |
| **秘籍 · 快捷键参考** | SketchUp、Rhino、AutoCAD 离线快捷键查询 |
| **胶囊 · 备份与迁移** | 应用记录与原文件统一打包，项目/日期范围、完整性校验、换机恢复和路径重建 |

右键小球可打开 mini 功能栏：**星笺**提供任务节点时间线，支持与星砂关联待办、AI星流同步；**星轨、星镜**仍为规划入口。中键点击小球可打开 **STArra 星灵** 对话。

## 桌面交互与外观

功能栏支持拖动排序；小球的主功能、mini 栏与对话入口各自保留。提供 13 套配色、8 种材质，可分别调整配色与质感强度。液态玻璃保留边缘高光与可选系统背景模糊，真实桌面连续折射没有启用。

MCP 状态可使用双星轨道或流光光环，光圈大小与粗细可调；提示气泡跟随小球移动。系统开启减少动态效果时，相关反馈使用静态提示。

## v0.3.3：看清项目文件、版本与来源

### 文件、时间与关系，三个工作视角

文件看板读取你确认的项目目录，不移动、重命名或删除原件。支持卡片/列表、类型/状态/日期筛选，以及修改时间、名称、大小排序。文件变化后需要手动刷新。

关系图以圆点、连线和文件名展示关联，支持平移、缩放、节点排布与范围聚焦。**导出/生成、引用、设计参考、分支关系均由用户确认**；来源状态变化后提醒核对，不自动修改下游文件。

### 人工版本归组，真实内容快照

相同扩展名的文件可归入版本组，并区分当前工作版本、确认稿与交付稿。相近名称只作为候选提示，不会自动认定版本先后。

主动保存快照或命名项目节点，会复制真实文件内容并记录 SHA-256。支持历史预览、并排参考与校验后恢复为副本，拒绝覆盖已有文件。**未主动保存的覆盖历史无法补回**；多文件项目节点也不等于设计软件的原子保存。

默认快照总额度为 5 GB，可调整为 1–100 GB；单文件最多 2 GB，每次最多选择 60 个文件。扫描上限为每项目 12,000 个条目，关系图单次最多展示 180 个文件，可先搜索和筛选缩小范围。

## 一个完整的设计工作流

1. **收集背景**：建立织梦台项目，选择当前收集目标，把网站、素材与提示词关联到项目。
2. **梳理方案**：在星砂记录决策与行动项，通过星笺安排任务；AI 提取的任务汇入对应分类的「AI星流」。
3. **理解文件**：扫描项目目录，筛选模型、图纸与文档，人工确认版本组和导出、引用、参考关系。
4. **保存节点**：在评审或交付前，主动保存相关文件的内容快照或项目节点，为后续核对保留依据。
5. **迁移继续**：用胶囊扫描并打包所需原件、应用记录和快照，在新电脑恢复并重建已打包路径。

## 可选 AI 与外部 Agent

### 星灵：让模型调用工具完成工作

中键呼出星灵，使用你配置的模型查询资料、管理待办、读取应用内容或生成 Word、Excel、PDF、Markdown 等真实文件。工具的实际执行结果会回传给模型，生成文件提供打开与另存入口。

模型接口需兼容 Chat Completions 的 Function Calling；联网搜索需另行配置 Tavily。模型网页产品具备某项能力，不代表其 API 自动提供相同工具。

### MCP：连接外部 Agent 与本机工作空间

在「设置 → 外部 Agent」开启接入、授权文件夹，并将应用提供的 MCP 配置加入外部客户端。**STArra 需保持运行，外部 Agent 所在电脑需安装 Node.js。**

- 只读查询可直接执行；新建、修改、删除及有副作用的操作需要本次确认，批量清单可合并为一次确认。
- 文件访问限于用户明确授权的目录。模型规划不等于获得任意终端执行或通用电脑控制能力。
- Agent 可登记生成文件的真实路径并关联项目，也可保存卷轴的图片、提示词与参数，方便回到应用核对成果。
- 小球光环与跟随气泡显示连接、执行、确认及结果；外观设置中可选择光环样式、大小和粗细。

## 数据、隐私与备份边界

本地功能无需账号。应用记录默认沿用兼容数据目录 `%APPDATA%\musy-desktop-assist`；项目原件与外部引用保留在你选择的位置。

| 内容 | 存储与使用方式 |
| --- | --- |
| 收藏、便签、提示词及项目记录 | 保存在本机应用配置中 |
| 百宝匣素材 | 默认引用原件；剪贴板图片由资料库保存。回收区到期清理自有文件，外部引用原件保留 |
| 项目索引与内容快照 | 保存在当前配置的 `project-files` 中；主动快照占用额外磁盘空间 |
| AI 与联网操作 | 按需向你配置的服务发送当前操作所需内容、指令或工具结果，可能产生费用；不会因为“本地优先”而全部离线运行 |
| 外部 Agent | 按应用权限及授权目录访问；外部 Agent 自身在系统上执行的操作，不受 STArra 确认窗口统一管控 |

**胶囊是个人备份迁移包，不是脱敏交付包。** 项目/日期范围只筛选原文件；完整应用记录与当前资料库自有文件仍可能包含其他项目内容和模型密钥。分享前需自行核对内容。旧 JSON / 索引备份不包含全部原件；外部 Agent 授权与连接配置需在迁移后重新设置。

首次启动仅提供公开网站、原创卷轴示例与示意插画、离线快捷键、使用文档和演示，不含开发者私人项目、素材或密钥。已有用户编辑的内置笔记不会被新版文档强制覆盖。
