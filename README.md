# Musy Desktop Assist Software

面向设计工作者的桌面悬窗辅助工具（Desktop Floating Window Assistant for Designers）。

## 简介

一款运行在 Windows 上的桌面悬窗辅助工具，以迷你悬浮条 + 点击展开完整窗口的双形态交互方式，帮助设计工作者在日常工作中快速完成常见辅助操作。

## 特性（规划中）

- 迷你悬浮条，常驻桌面不遮挡工作区
- 点击展开完整功能窗口
- 面向设计工作者的辅助能力（待补充）
