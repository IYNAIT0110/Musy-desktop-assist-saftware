# 卷轴入门示例

v0.2.0 提供 3 条原创教学示例，应用首次初始化未创建过的卷轴库时自动加载。已有内容不覆盖，删除后不自动补回。

- [林间亭 · 清晨](01-pavilion-day.md)：母提示词。
- [林间亭 · 夜景](02-pavilion-night.md)：同一母提示词下的子版本，演示卡牌切换。
- [社区阅读室](03-library.md)：独立提示词，演示标签与编辑。

封面为 [源码中的原创 SVG 示意插画](../../src/renderer/src/assets/examples/)，不是生成效果图。示例正文和封面采用项目 MIT 许可。可以直接复制文字到新增卷轴，不需要 AI；也可以用卷轴的文档导入识别这些 Markdown 文件，此方式需用户自己的 AI 接口。

Markdown 文件用于阅读和复制，不是全量备份，勿用设置中的“恢复 musy-data.json”来导入。
